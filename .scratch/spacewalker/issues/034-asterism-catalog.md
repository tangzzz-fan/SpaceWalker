# 034 接入 318 星官与连线

## 目标

把「中国星空」从一个概念做成可看的东西：星官从按中文星名硬解析的 81 组，换成带官方成员与连线的全表；选中一个星官，天上能画出它的形状。

## 数据

来自 Stellarium `chinese` 星空文化（许可 CC BY-SA，见 THIRD-PARTY）。原始 `index.json` 318 个星官、1385 颗 HIP 成员星、240 KB。

两条预处理决定：

1. **不给星表换源**。现有 `stars.json` 是 HYG 5.5 等（2996 颗），没有 HIP 号。用 d3-celestial 的 `stars.6.json` 做 HIP↔坐标桥接，按 0.02° 最近邻给现有星补 `hip`，一颗星只认领一个 HIP、一个 HIP 只被一颗星认领。实测 2862 / 2996 匹配上（95.5%），未匹配的 134 颗都是 6 等附近的暗星。
2. **不把星表放到 6.0 等**。评估过：5.5 等能画出 215 个完整星官，6.0 等是 260 个，差 45 个；但换阈值要重建星表、改一批数量断言、多渲染 2000 颗暗星。先用现状，把阈值留作后续可选项。

离线生成脚本入库：`tools/build-catalogs.py`。此前星表生成脚本是一次性步骤、未入库，这次一并补上。

## 产出

`Sources/Resources/asterisms.json`（33 KB）：

| 指标 | 数值 |
|---|---|
| 星官 | 301（丢弃 17 个成员全不可见） |
| 有连线 | 227 |
| 线段 | 814 |
| 二十八宿 | 28 / 28（「星宿」在源数据里 `native` 为空，按 `pronounce: Xing Xiu` 补回） |

两个重名保留：井宿「积水」与胃宿「积水」、井宿「五诸侯」与太微「五诸侯」——这是星官体系本身的同名，用 `CON chinese NNN` 的 id 区分，检索时并列出现。

单星官（如「积水」的连线是 `[[19167, 19167]]`）没有线可画，但保留在分组里，可以搜到、可以定位。

## 实现

**模型**：`Star` 增加 `hipparcos: Int?`；新增 `Asterism`（id / name / members / lines），`AsterismCatalog` 从 bundle 加载。

**分组**：`SkyGroupIndex.groups` 改为遍历 `AsterismCatalog.all`，用 HIP 反查星表成员。`starNames` 语义保持不变——只放可选中星（准星能落到的），所以组卡「N 颗」仍是可选中数；另加 `lineCount` 表示可绘制段数，副标题变成「7 颗 · 6 段连线」。

**渲染**：`SkyScene.buildAsterisms` 把所有星官折线合并成**一个**网格（draw call +1），管径 0.026，暖金色 `(0.88, 0.76, 0.52)`，亮度 0.72。

一个必须记的坑：星官线最初和星座线一样落在半径 50 的球面上，结果被更粗的星座线整体压住，只剩零星几段露出来。改成 **49.4**（更靠近观察者）之后才稳定浮在上面。

**交互**：底栏加「星官」开关，默认关闭；从找星面板聚焦任意星官时自动打开。开启时图标文字变金色。
