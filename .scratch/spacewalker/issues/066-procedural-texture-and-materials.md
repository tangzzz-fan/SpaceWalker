## 背景

现在每件一个纯色 `SimpleMaterial`。1:20 的模型在屏幕上只有几十像素宽，**体积感几乎全靠明暗层次**，
纯色平板没有层次，因此无论加多少几何都像塑料玩具。

这一层是观感跳变最大的一层，也是最容易踩性能坑的一层：`rebuild()` 每次进路由都重建整棵树，
如果贴图跟着重建，切三次路由就吃掉三次贴图生成成本。

## 范围

- 贴图生成器：`CGContext` 画到 `CGImage` 再转 `TextureResource`，与 `SpaceEnvironment` 的既有路线一致。
  - 白 MLI：纵向板缝 + 少量横向加强线 + 极轻噪声。
  - 金箔：不规则褶皱（几条随机折线 + 柔化）+ 噪声。
  - 电池片：网格（横 4 × 纵 N）+ 细边框。
- 三档材质：白 MLI（roughness 0.72 / metallic 0）、金箔（0.38 / 0.85）、电池片（0.28 / 0.1 + 极低自发光）。
- 光照：保留现有 key + fill，**补一盏从后侧来的冷轮廓光**——黑底上深色件会丢轮廓，这盏灯是分离度来源。

## 验收标准

- [ ] 材质档 ≥ 3，且每档有独立的 roughness/metallic 组合。
- [ ] 贴图生成**恰好一次**：静态缓存 + 计数器，进出路由 3 次后计数仍为 1。
- [ ] 贴图分辨率 ≤ 1024²，单张解码后 ≤ 4 MB，总量不与包体预算（NFR-09）冲突。
- [ ] 侧视截图：舱体面板能看出分块，翼能看出电池片网格。
- [ ] 帧率不回退：真机 ≥ 25fps（NFR-01 C 阶段）。
- [ ] 既有 310 项测试零改动通过。

## 测试缝

贴图生成是纯函数（输入尺寸，输出 CGImage）→ 可测尺寸与像素采样（抽几个点断言缝线颜色）。
缓存次数用计数器断言，这是最容易静默退化的点。

## 备注

- 不要把 `TextureResource` 放进 `@State` 或随实体生命周期创建；它必须是静态的，否则路由往返会重新生成。
- 噪声用固定种子，保证两次构建截图可比（像素比对是既有验证手法）。
- 若轮廓光导致金属件过曝，优先降 intensity 而不是删灯——删灯会丢掉分离度。

## 实现记录

- 三张 512² 程序化贴图：白 MLI（竖缝 64 px + 横加强线 + 噪声）、金箔（70 条折线 + 噪声）、
  电池片（8×8 格 + 银色边框）。全部用 `CGContext` 画完转 `TextureResource`，仓库零图片。
- 缓存是 `static` 字典 + `generationCount` 计数器，`rebuild()` 不参与生成。三个断言守着：
  每种表面可取、重复取不增长、**路由重建三次计数不变**。
- 六档材质：白 MLI（0.72 / 金属 0）、金箔（0.38 / 0.85）、电池片（0.28 / 0.10 + 低自发光）、
  舱段（0.66 / 0）、飞行器（0.50 / 0.05）、硬件（0.42 / 0.65）。断言要求三档主材质的粗糙度与金属度两两不同。
- 给 `revolve` 补了 UV（侧面 u=边序号、v=轴向比例；端盖用极坐标）——没有 UV 锥段贴不上图。
- 轮廓光用 `look(at:from:)` 摆位，不手算四元数：从 (-1.8, 1.2, -1.6) 照向包围盒中心。

**为什么之前的默认视角发闷**：白 MLI 原来写的是 `isMetallic: true`。金属度 1.0 的材质几乎没有漫反射，
只反射环境——而环境是暗色星系天空盒，于是白舱看起来像照了一面黑墙。改成金属 0 之后立刻变亮，
这才是不靠调曝光的正解。

**顺手挖出一个假通过**：`triangleEstimate` 只数顶层实体的 `ModelComponent`，而翼、飞船、实验舱的网格
现在都挂在子节点上，日志里报 **256** 三角形——真实值是 **2288**，少报了 9 倍。
预算断言如果照着 256 判，等于永远通过。已改成递归统计，并加 `testSceneStaysWithinTriangleBudget`
（>1000 且 ≤20000），下限那条专门防"计数又退化成只数顶层"。

**实测**（模拟器，`tiangong.build` 日志）：冷构建 109–150 ms，2288 三角形，328 项测试 0 失败。

**遗留**：贴图分辨率固定 512²，近看仍有颗粒感；若 M3.1 盲测后要再提，优先加 1024² 的电池片，
而不是给所有表面加分辨率。
