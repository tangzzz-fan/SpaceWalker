## 背景

天宫一号的结局是 2016-03-16 终止数据服务、2018-04-02 再入南太平洋中部。
这是整个产品最有戏剧性的收尾，也是最容易被忽略的一条史实——大多数太空 App 只讲"它是什么"，
不讲"它后来怎么了"。

放在三任务 + 姿态调整之后，作为收束，而不是开场。

## 范围

- 解锁条件：三任务完成 + 姿态调整看过（070）。
- 「最后一圈」约 20 秒，三拍：
  1. 轨道高度衰减（相机拉远，天宫缓慢下沉，背景星空不变）。
  2. 大气加热（材质 `emissiveColor` 渐强 + 尾迹用少量加法混合的三角面，不用粒子系统）。
  3. 解体（五个模块分段淡出，先翼后舱段）。
- 结束停在史实卡：2018-04-02 · 再入 · 南太平洋中部。可重看。
- 全程可跳过；跳过直接落到史实卡。

## 验收标准

- [ ] 三拍顺序正确，总时长 18–22s；跳过 ≤ 0.2s 生效。
- [ ] 史实卡与 `TiangongHistory` 同源；不出现"空间站"。
- [ ] 重看 3 次无状态残留（材质自发光归零、模块可见性复位）。
- [ ] 不引入粒子系统与后处理（NFR-01 的 C 阶段口径不放宽）。
- [ ] 默认视图截图与 068 基线差异为 0——彩蛋是独立流程，不改默认场景。

## 测试缝

三拍是状态机（`coast → heating → breakup → card`），可对时序与"跳过"做纯值断言。
自发光强度是可读属性，重看后断言归零。

## 备注

- 尾迹用三角面不用粒子：粒子的 draw call 不可控，会撞 068 的 ≤40 预算。
- 情绪风险已知：一个被拆开玩熟的模型突然烧掉。缓解是"它是真实的"这句话本身，
  史实卡上写清楚日期与落区，不做煽情文案。
- 若时间不够，可以砍成两拍（加热 → 卡），不要砍史实卡。

## 实现记录

**状态机**：`TiangongReentry` 纯值，三段 7.5 + 6 + 6.5 = **20 s**（门禁要求 18–22 s）。
`phase(at:)` 是唯一的时间→相位映射，`step` / `skip` / `progress` 都从它派生，
所以「跳过」不会另算一套时间。淡出窗口：两翼 0–0.35、资源舱 0.25–0.58、实验舱 0.45–0.78、
神舟 0.65–1.0，窗口重叠，读起来是逐段散开而不是五个一起消失。

**尾迹**：一条 `revolve` 母线旋转体（24 边、约 240 三角形），不是粒子——粒子数量不可控，
会撞 40 draw call 预算。挂在**资源舱节点下**，下沉、淡出、预算统计全部随父节点走。
RealityKit 的 `UnlitMaterial.Blending` 只有 opaque / transparent，**没有加法混合**，
所以用透明混合的亮橙代替；在深色星空上观感接近，也就不必自造 `CustomMaterial`。

**两步渲染都靠肉眼看出来**：
1. 第一版尾迹挂在 root 上，而模块在下沉 → 尾迹悬在舱体上方 0.42 m，画面里是一块漂浮的橙色多边形。
   改挂资源舱后消失。
2. 第一版只加自发光，白色蒙皮 + 橙色发光 = **粉色塑料**。改成基色与自发光同向渐强才读成高温。
   基色必须改，是因为「热」的视觉本质是反照率让位于自发光，只加发光只会变亮不会变热。

**下沉量 0.42 → 0.16**：整机才 0.52 m，0.42 的下沉会把模型推出画面；配合相机拉远 1.3，
0.16 既有「在掉」的感觉又不丢构图。

**解锁条件改了口径**：070 最终做成史实卡而不是动画，所以「看过姿态调整」的等价条件是
**打开过一次史实面板**（`markMilestonesRead`）。FR-C-11 已回填说明。

**一处容易忽略的破坏**：`startReentry` 原本调 `endDocking()`，那会把飞船推回待对接位
（`shenzhouCenter`），而「最后一圈」恰恰发生在对接完成之后——飞船会在彩蛋开场瞬间倒飞出去。
改成只把 `dockingActive` 置 false，位置保持对接态。

**默认视图未改**：同机位（yaw 1.5708 / pitch 0.02 / dist 3.9 / phase 0.18 / 冻结）重拍并与
`docs/gates/M3.1/gate-side.png` 做差：**平均差 0.059/255**，即渲染噪声级别。
尾迹默认 `isEnabled = false`，关闭时不进 draw call 统计。

**预算实测**：实体 53 / 60，模型 **39 / 40**（尾迹是第 39 个），三角形 6244 / 20000，构建 174 ms。

**验证**：358 项测试 0 失败（新增 10 项：三拍边界、总时长门禁、步进不越界、跳过幂等、
翼先散、alpha 单调、解锁条件、收束卡同源、尾迹只在彩蛋里、重看三次全复位）。
证据 `docs/gates/M3.1/073-{coast,heating,breakup,card}.png`。

**取证开关**：`SPACEWALKER_TG_REENTRY=<秒>` 跳过解锁并直接定位到该秒（配合 `_FREEZE` 定格），
四张证据图即由此产出。
