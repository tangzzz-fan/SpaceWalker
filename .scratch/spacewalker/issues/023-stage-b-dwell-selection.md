## 背景

022 只做了轻点选中。FR-B-03 要求"准星对准并停留 0.6s 即选中"，这是 O2 KR1（30 次预设目标、成功率 ≥ 90%）的主路径。A 阶段 005 已暴露手持抖动会让视锥判定不可分辨（预演 H4），所以停留判定必须有衰减与重触发约束，不能是"帧计数"。

## 范围

- 可选中集：有专名且视星等 ≤ 4.5（288 颗）；其余 2708 颗仅作背景，不可命中。
- 视觉区分（2026-11-07 决策）：可选星保持原亮度与尺寸，背景星压暗到 0.38 亮度并缩小到 0.62 倍，合并为单一网格；总 draw call 6 + 1 = 7，仍在 FR-B-01 的 ≤10 预算内。
- 命中判定：准星 44pt（半径 22pt），先用角距预筛 ≤ 4° 取最近 4 颗，再用 `RealityViewCameraContent.project` 复核像素距离，避免每帧对 2996 颗做投影。
- 停留状态机 `DwellSelector`：同一目标累计 0.6s 触发；换目标立即归零；丢失目标按 1.5/s 衰减（抗抖动）；触发后需离开目标才可再次触发。
- 反馈：准星外圈进度环 + 轻触觉。
- 轻点与准星走同一候选集与同一命中半径，结果一致。
- 探针：`SPACEWALKER_PICKPROBE=1` 时对全部 288 颗做"旋转到中心 → pickAtCenter 取回自身"遍历，输出 `sky.pickProbe ok=n/288`。

## 验收标准

- [x] 单测：停留 0.59s 不触发、0.61s 触发一次；换目标重新计时；丢失目标衰减；触发后不重复。
- [x] 单测：角距预筛只返回 ≤ 4°，亮星在同角距下优先。
- [x] `pickProbe` 覆盖 288 颗全部取回自身（模拟器与真机均 `ok=288/288`）。
- [ ] 真机：准星对准 Sirius 停留 0.6s 出卡；移开不误触发。
- [ ] 真机：轻点与准星对同一颗星结果一致。
- [ ] 真机：30 次预设目标成功率 ≥ 90%、误选 ≤ 2（人工执行，agent 不判定）。
