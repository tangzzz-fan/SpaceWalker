## 背景

062 当年否决"线框表达"，是因为它在评估它能不能**替代**实体表达——结论是不能，太抽象。
但它**作为附加模式**价值完全不同：和"史实/参数"的叙事天然契合，也是这个产品区别于
"又一个太空 CG"的地方。

工作量几乎全在 UI（标注布局），不在 3D。

## 范围

- 「工程图」模式：几何换 unlit 材质（深底 + 浅色线框/淡色实体），关掉方向光与 IBL。
- 屏幕空间标注四条：全长 10.4 m、最大直径 3.35 m、翼展 18.405 m、转移通道 0.8 m。
  数值从 `TiangongModel` 取，**不许另写字面量**。
- 正 / 侧 / 俯三视图快捷切换（固定 rig 角度 + 正交感：拉远 + 小 FOV）。
- 默认关闭。

## 验收标准

- [ ] 四条标注数值与 `TiangongModel` 常量逐位一致（用测试断言，不靠肉眼）。
- [ ] 标注两两不重叠、不出屏；任意三视图切换后仍然不重叠。
- [ ] 模式切换 ≤ 0.3s，不触发整树重建（`rebuild()` 只在路由切换时调用）。
- [ ] 关闭模式后回到默认视图，光照恢复。
- [ ] 默认视图截图与 068 基线差异为 0。

## 测试缝

标注锚点 = 几何端点的屏幕投影，可对"投影是否在屏幕内""两标注矩形是否相交"做纯函数断言。
这是少见的"UI 布局可单测"场景，值得做。

## 备注

- 三视图用"拉远 + 小 FOV"模拟正交，不用真正交相机——RealityKit 的虚拟相机不好切投影矩阵，
  而 1:20 的尺度下透视误差在标注精度内可接受。这一点要写在代码注释里说明是近似。
- 标注不要用 3D 文字，用 SwiftUI 覆盖层投影定位，与现有标签层同一套机制（但要解决 062 的白屏坑：
  锚点不进 `@State`，用 `TimelineView` 自刷新）。
