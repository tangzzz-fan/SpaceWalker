## 背景

A 阶段原设计依赖平面锚定。M0 证明锚定可用，但产品侧确认：太阳系放在真实房间里可读性差，且每轮验证要走四到五次真机往返。ADR-0003 决定 A 阶段默认走虚拟相机 + 星系天空盒，平面锚定降为可选「放进房间」入口。

## 范围

- `camera: .virtual` + `environment: .skybox(EnvironmentResource)`，默认不启动 ARKit、不请求相机权限。
- 太阳 + 8 行星，程序化球体，轨道半径与天体半径做非线性压缩并标注"非真实比例"。
- 轨道线（自建环面网格）、土星环、点选信息卡、时间轴（流速 + 暂停）、轨道显隐。
- 轨道相机：拖动旋转、双指缩放，俯仰与距离夹取。
- 「放进房间」入口：进入既有 `SessionView`（spatialTracking + 平面锚定）。
- 素材来源面板（NASA 底图与数据致谢）。

## 验收标准

- [x] 冷启动后在模拟器可见完整星空 + 太阳 + 8 行星（真机待测）。
- [x] 9 个天体的屏幕投影点各自能拾取回自身（`pick.roundtrip ok=9/9`）。
- [x] 时间轴按 `天/秒` 推进，暂停后相位不变；切换选中不重置时间。
- [x] 关闭轨道后环面隐藏；相机俯仰/距离夹取在允许区间内。
- [ ] 真机：冷启动到可见太阳系 ≤ 3s（模拟器 868ms 环境加载 + 首帧，待真机复核）。
- [ ] 真机：平均帧率 ≥ 55fps（探针 005 复用）。
- [ ] 「放进房间」进入与退回各一次，时间轴状态不丢。
- [ ] 素材来源面板在真机可打开，文案不与系统深色模式冲突。

## 测试缝

1. `SolarLayout`（纯函数）：轨道半径压缩、天体半径、相位、位置。
2. `SolarSystemReducer`：推进/暂停/限幅/选中/轨道显隐/重置/天数回绕。
3. `OrbitRing.torus`（纯数据）：顶点与索引数量、法线单位化、环带半径范围、索引越界。
4. `OrbitRig`：距离、俯仰与缩放夹取。
5. `SpaceEnvironment`（真机/模拟器）：底图可解码 → 天空盒可用；失败回退程序化。
