## 背景

拆解是 C 阶段"做"的第一步：用户能把太阳翼、实验舱、资源舱分离开，并保持可操作。
要求只有三条：分得开、选得中、回得去。

blocked_by 062 是因为：拆解靠"看得清哪个是哪个"，辨识度没过关就拆，用户分不清飞出去的是舱还是板。

## 范围

- 选中沿用 A 阶段的命中规则（`CollisionComponent` + `InputTargetComponent`，取最近者）。
- 分离：沿模块装配轴向外移出，缓动 0.4s，带触觉；音效可静音。
- 分离后保持悬浮、可再次选中、可单独装回、可一键全部复位。
- 选中态与分离态都是 `TiangongSession` 的状态，View 只发命令。

## 验收标准

- [x] 四个模块（实验舱、资源舱、左右太阳翼）均可独立分离与选中，分离后位置稳定。
- [x] 分离后无穿模、无丢失；分离让拾取自检从 4/5 升到 **5/5**（原左翼被实验舱遮挡）。
- [x] 复位回到绝对初值：`TiangongDisassembly.separatedPosition` 与 `restPosition` 都是纯函数，
      复位不读当前变换，误差为 0（`testRestPositionIsAbsolute`）。
- [x] 分离/复位有触觉（`UIImpactFeedbackGenerator.light`）；音效未做。
- [x] 选中态与分离态正交：`selected` 与 `separated` 两个独立字段。
- [x] 连续 10 轮拆装无累积漂移（由绝对初值保证，测试断言）。
- [x] 神舟不参与拆装（`testShenzhouIsNotDismantlable`），留给 018 对接。

## 实现记录

- 每个模块沿**自己**的装配轴外移：实验舱 +Z、资源舱 −Z、左翼 −X、右翼 +X，
  轴两两不同（`testAxesAreDistinct`），距离 0.12m（展示坐标）。
- 视觉验证：`SPACEWALKER_TG_SEPARATED=lab,leftWing` 启动即分离，供无头截图。
  截图确认实验舱前移、左翼外移、标签跟随、无穿模。
- 触觉只在分离/装回时给一次，不在动画每帧给。

## 测试缝

- 分离位移：输入模块 ID 与当前变换 → 输出目标变换（纯函数）。
- 复位状态：输入当前模块集合 → 输出初始变换集合（纯函数，绝对初值）。
- 状态机：输入事件序列 → 输出选中/分离集合（纯函数）。

## 备注

- 不使用物理引擎做分离，避免非确定性；悬浮为静态姿态。
- 真机验收由 020 承接。
