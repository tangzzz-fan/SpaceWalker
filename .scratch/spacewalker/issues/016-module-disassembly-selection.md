## 背景

拆解是 C 阶段"做"的第一步：用户能把太阳翼、实验舱、资源舱分离开，并保持可操作。
要求只有三条：分得开、选得中、回得去。

blocked_by 062 是因为：拆解靠"看得清哪个是哪个"，辨识度没过关就拆，用户分不清飞出去的是舱还是板。

## 范围

- 选中沿用 A 阶段的命中规则（`CollisionComponent` + `InputTargetComponent`，取最近者）。
- 分离：沿模块装配轴向外移出，缓动 0.4s，带触觉；音效可静音。
- 分离后保持悬浮、可再次选中、可单独装回、可一键全部复位。
- 选中态与分离态都是 `TiangongSession` 的状态，View 只发命令。

## 验收标准

- [ ] 三个模块均可独立分离与选中，分离后位置稳定不漂移。
- [ ] 分离过程无穿模、无丢失，10 秒内仍可重新选中。
- [ ] 复位后回到初始装配状态，展示坐标误差 < 2mm（约等于真实 4cm）。
- [ ] 分离/复位有触觉，音效可关闭。
- [ ] 分离状态下切换选中不触发误操作（选中态与分离态正交）。
- [ ] 连续拆装 10 轮后，模块变换无累积漂移（复位用绝对初值，不用相对增量）。

## 测试缝

- 分离位移：输入模块 ID 与当前变换 → 输出目标变换（纯函数）。
- 复位状态：输入当前模块集合 → 输出初始变换集合（纯函数，绝对初值）。
- 状态机：输入事件序列 → 输出选中/分离集合（纯函数）。

## 备注

- 不使用物理引擎做分离，避免非确定性；悬浮为静态姿态。
- 真机验收由 020 承接。
