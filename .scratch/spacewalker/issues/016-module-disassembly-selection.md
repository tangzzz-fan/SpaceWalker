## 背景

拆解是 C 阶段"做"的第一步：用户能把太阳翼、实验舱、资源舱分离开，并保持可操作。基础定调只要求"分得开、选得中、回得去"。

## 范围

- 模块选中：沿用 A 阶段的命中规则（`CollisionComponent` + `InputTargetComponent`）。
- 分离：沿模块轴向移出，缓动 0.4s，带音效与触觉。
- 分离后的模块保持悬浮、可再次选中、可一键复位。

## 验收标准

- [ ] 三个模块均可独立分离与选中，分离后位置稳定不漂移。
- [ ] 分离过程无穿模、无丢失，10 秒内仍可重新选中。
- [ ] 复位后回到初始装配状态，误差 < 2mm。
- [ ] 分离/复位有音效与触觉，且可静音。
- [ ] 分离状态下切换选中不触发误操作。

## 测试缝

- 分离位移解算：输入模块 ID 与当前变换 → 输出目标变换（纯函数）。
- 复位状态：输入当前模块集合 → 输出初始变换集合（纯函数）。

## 备注

- **基础定调，后续可改**：缓动时长、分离距离、音效素材均可调。
- 不使用物理引擎做分离，避免非确定性；悬浮为静态姿态。
- 真机验收由 020 承接。
