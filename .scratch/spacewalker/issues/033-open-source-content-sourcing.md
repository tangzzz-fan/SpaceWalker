## 1. 中国传统星官全表（最高优先级）

### 是什么

Stellarium 的 `chinese` 星空文化包（`Stellarium/stellarium-skycultures` 仓库），一个 `index.json` 描述整套中国传统星官体系。

已核实（直接拉取该文件统计）：

| 指标 | 数值 |
|---|---|
| 星官条目 | 318 |
| 其中带连线 | 312 |
| 连线涉及 HIP 星 | 1385 |
| 有中文名（native） | 315 |
| 文件体积 | 240 KB |

数据结构极简，一个星官一条：

```json
{
  "id": "CON chinese 001",
  "lines": [[20889, 20648, 20455, 20205], [21421, 20885, 20713, 20205, 18724], [21421, 21683]],
  "common_name": { "native": "毕宿", "english": "Net", "pronounce": "Bìxiù" }
}
```

`lines` 是若干条折线，每段是一串 HIP 号。这正是画连线需要的全部。

### 许可：可用，且与现状兼容

仓库根是 AGPL-3.0，但**该文化目录自己声明了另一套许可**（`chinese/description.md` 第 258 行起）：

```
## License

Su Song and Suzhou maps images: Public Domain

Text and line: CC BY-SA
```

即：文字与连线 CC BY-SA，两张古图公有领域。

这与项目现状完全一致——`stars.json` 本来就是 HYG 的 CC BY-SA 4.0，`LICENSE` 里已有「CC BY-SA 例外」条款。接入后只需在 `THIRD-PARTY.md` 加一行，并把导出的 `asterisms.json` 标注为 CC BY-SA。

**不要**去碰 `stellarium-skycultures` 的其它目录（多数是 AGPL 或 CC BY-NC-ND，比如「西游记」文化是 CC BY-NC-ND 4.0，商用与演绎都不行）。

### 覆盖率实测：这是关键决策数据

星官成员星偏暗。用 6.0 等星表做交叉（d3-celestial `stars.6.json`，5044 颗全天空）：

| 阈值 | 命中 | 占比 | 能完整画出的星官 |
|---|---|---|---|
| 6.0 等 | 1296 / 1385 | **93.6%** | **260 完整 / 50 部分 / 2 全缺** |
| 5.5 等（现状） | 1189 / 1385 | 85.8% | 完整率明显下降 |

结论：**把星表阈值从 5.5 放到 6.0，是接入 318 星官的前提条件，且效果确定**。6.0 等是肉眼在暗天条件下的极限，对「举着手机看天」的真实可见星等来说并不夸张。

### 怎么进来

1. 重新生成星表：HYG（建议直接升到 v4.4，119,614 颗）过滤 `mag ≤ 6.0`，**新增 `hip` 字段**（HYG 的 `hip` 列），保留现有 `ra/dec/mag/ci/name/con`。
   - 预估星数：5,000–9,000（取决于是否合并双星；HYG 含重复条目，建议沿用现有 0.05° 内合并策略）。
   - 体积：约 300–500 KB JSON，可接受。
2. 生成 `asterisms.json`：从 `chinese/index.json` 抽取 `{name, lines: [[hip...]]}`，只保留能从新星表里解析出 ≥ 2 颗星的星官（预估 310 个左右）。
3. `SkyGroup` 增加 `.lines: [[Star]]`；现有「按中文星名解析星官」的逻辑保留为 fallback，数据源切换为显式表。
4. `SkyScene` 给星官建一套连线节点（复用星座连线的材质与粗细），默认关闭，与「星座」按钮并列成「星官」开关。
5. 组卡增加「星官」类别下 318 项，检索沿用现有四路。

### 风险

- 318 个连线节点会增加 draw call。现有星座 138 条线走单批，星官 312 组建议同样合并成**一个网格**（所有星官折线顶点塞进一个 buffer），draw call 只 +1。
- 两个星官可能共用同一颗星（如天市垣与邻近星官），连线重叠属正常，不需去重。
- 需确认 CC BY-SA 版本号（文件只写「CC BY-SA」未标版本）；保守按 4.0 处理并在文档注明「未标版本，按 4.0 理解」。

## 2. 中文星名扩充

`chinese/index.json` 的 `common_names` 有 3027 条，但**只有英文**（`"Northern Pole I"`、`"Crown Prince"`），中文在 `po/` 翻译文件里。要拿到「天枢」「帝」这样的中文，需要解析 `po/zh_CN.po` 或从星官表反推。

更实际的路径：星官表里 315 个官名（毕宿、太微右垣、天市左垣…）已经覆盖了「星属于哪个官」，而现有 `AsterismParser` 正是靠中文星名的前缀解析星官。两者可以互为校验。

建议：
- 先接 318 官名（确定可拿、许可干净）。
- 单颗星的中文名（天枢、摇光、参宿四…）继续手工维护，从公开星表核对，不引 po 文件（翻译文本的许可随 po 头声明，未必是 CC BY-SA）。

## 3. 星座艺术版画（星卡视觉）

**Urania's Mirror**（Sidney Hall，1824/1825，32 张）—— 公有领域，Wikimedia Commons 有 3500–5000 px 的修复版与原始 TIFF。

用途不是替换 3D 轮廓（那是矢量动画，更好），而是给**星座信息页做背景/插图**：一张古典版画 + 现代轮廓，对照感很强，也很适合截图传播。

另有 Hevelius《Firmamentum Sobiescianum》(1690)、Bode《Uranographia》(1801) 同为 PD，可作备选风格。

成本：32 张 × 每张压到 800px JPEG ≈ 3–5 MB。按星座按需下载会破坏离线体验，建议只内置 31 个已有释义的星座图，或统一压到 600px 控制在 1.5 MB。

## 4. 深空天体

`dso.csv`（HYG 仓库 `misc/`，227,285 条）实测亮度分布：

| 阈值 | 数量 |
|---|---|
| ≤ 6.0 等 | 110 |
| ≤ 8.0 等 | 336 |
| ≤ 9.0 等 | 491 |

绝大多数是星系（222,949），肉眼都看不到。**全量接入没有意义**，反而拖慢渲染与拾取。

建议只取 **Messier 110 个**（M31 仙女、M42 猎户、M45 昴星团、M13 球状星团…），这批是「举手机真能看到」的目标，也是天文入门唯一记住的一批。110 个点可以并进现有星野网格，只加一个 `kind: dso` 标记，拾取后出「深空卡」而不是「星卡」。

许可需单独核实（`dso.csv` 的 `dso_source` 字段混了多个来源），Messier 编号与坐标属事实性数据，卡片文案自写即可。

## 5. 天体位置计算（行星、月相、升落）

现在项目只有恒星 + 手算恒星时/地平转换。缺太阳、月亮、行星，也缺「今夜几点天黑」「月相如何」——这些恰恰是「今夜此刻」最需要的上下文。

**AstronomyKit**（`heirloomlogic/AstronomyKit`，MIT，包装 Don Cross 的 Astronomy Engine v2.1.19，Swift 6 / iOS 16+）提供：

- 日月行星视位置（VSOP87 + NOVAS，误差 ±1 角分）
- 升落与晨昏蒙影（民用/航海/天文）
- 月相、月地距离、天平动
- 行星合/冲、水星金星大距
- 判断某点属于哪个星座

接入后可以做的：
- 天空里画一个月亮（真实相位与位置），夜间观星的第一参照物
- 时间滑块旁显示「日落后 1h 22m」「月亮 87% 盈凸」
- 今夜榜单增加「月光干扰」维度（满月时暗星看不见，这是真实观测逻辑）
- 「此刻最佳」从「星座高度」升级为「实际可看」

成本：一个 SPM 依赖，约 1 MB 源码，无网络。若不想引依赖，也可以只抄 VSOP87 截断项自己算月亮（约 300 行），但没必要。

## 6. 恒星物理量（星卡补全）

HYG 源数据里本来就有的字段，现在被丢弃了：

| 字段 | 用途 |
|---|---|
| `dist` | 「632 光年」——星卡最有冲击力的一行 |
| `spect` | 「B8 蓝白」——配合现有 `ci` 色指数做色名 |
| `absmag` | 真实亮度，可做「比太阳亮 1 万倍」 |
| `proper motion` | 长期漂移（暂不需要） |

只需在生成星表时多带 2 个字段（`dist`、`spect`），JSON 体积增加约 15%。星卡从「名字 + 星官 + 封神」升级为「名字 + 星官 + 封神 + 距离 + 光谱」。

## 7. 暂不接入

| 内容 | 原因 |
|---|---|
| Gaia DR3 全量 | 18 亿条，与「举手机看天」无关 |
| Stellarium `constellationsart`（Johan Meuris） | Free Art License，copyleft，已排除 |
| 「西游记」星空文化 | CC BY-NC-ND 4.0，禁商用禁演绎 |
| 卫星 TLE / 流星雨 ZHR | 要联网更新、要时效维护，与离线定位冲突 |
| 光污染地图 | 需按经纬度取瓦片，离线化成本高，收益偏弱 |

## 建议的推进顺序

| 阶段 | 内容 | 依赖 |
|---|---|---|
| P1 | 星表加 `hip` + 放到 6.0 等；接入 318 星官与连线；星官开关 | 无 |
| P2 | 星卡补距离/光谱；Messier 110 | P1 的星表 |
| P3 | 星官连线做成可点亮（选中星官时描边，其余压暗） | P1 |
| P4 | AstronomyKit：月亮 + 月相 + 晨昏；今夜榜单加月光维度 | 无（可并行） |
| P5 | Urania's Mirror 作星座信息页插图 | 无 |

P1 是分水岭：做完之后，「中国星空」这个卖点才算真正立住——现在是 81 个组、无连线，做完是 318 官、312 组连线、可点亮。
