# 035 今夜导览

## 问题

「今夜此刻最适合看」是个排序列表：仙女座 79°、白羊座 66°、仙后座 62°……数字都对，但用户看完仍不知道**抬头的第一眼该看哪里**，也不知道**怎么认出它**。

## 做法

把列表变成一条可直接照着走的路线：

```
此刻 21:33，仙女座几乎就在头顶，是此刻最值得抬头看的一个。

1  仙女座              高度 79° · 东北
   三颗星连成一线，从壁宿二往东北数是 M31 的方向，肉眼是一小团雾。
   最佳观赏 10-12 月 · 5 颗可选

2  白羊座              高度 66° · 东
   三颗星组成一个钝角小三角，娄宿三最亮，秋天在东方。
   …
```

三段构成：

1. **headline**：时刻 + 榜首目标 + 方位措辞。方位按高度分四档——≥70°「几乎就在头顶」、45–70°「高悬在 X 方」、20–45°「挂在 X 方约 N° 高」、<20°「刚爬上 X 方低空」。高处不提方位，因为抬头就是。
2. **每站一句辨识提示**：不看坐标、靠形状认。31 个有连线的星座各写一条，全部覆盖（单测锁住，新增星座必须补提示）。
3. **每站可点**：关闭导览 → 聚焦该星座，自动打开星座连线。

入口在找星面板「今夜此刻最适合看」的右上角，取榜单前 4 站。

## 实现

- `TonightTour`：纯数据，`build(picks:date:limit:)` 可测；`placement(_:)` 四档文案单独抽出。
- `SkyTips`：31 条中文辨识提示，按星座中文名索引。
- `TonightTourView`：卡片流，深色，每站标题 / 方位高度 / 提示 / 最佳观赏。
- `StarFinderView` 加 `referenceDate`（跟随时间滑块的偏移）与 `initialTour`。
