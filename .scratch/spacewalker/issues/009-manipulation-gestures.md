## 背景

iOS 没有 `ManipulationComponent`（visionOS 26+），拖拽、缩放、旋转必须用 SwiftUI 手势 + 命中组件自行解算。

## 验收标准

- [ ] 单指拖动移动选中天体，跟手延迟 ≤ 50ms（触摸到 transform 更新）。
- [ ] 双指捏合缩放整体，范围 0.3x–3x，连续无跳变。
- [ ] 双指旋转绕竖直轴，角度变化线性。
- [ ] 拖到桌面以下被约束；相机过近时近处天体淡出。
- [ ] 连续拖动 5 秒，单帧回退 < 2mm。
- [ ] 拖动/缩放/旋转互斥，同一帧只有一个主交互。

## 测试缝

- 变换约束：输入手势增量 + 当前变换 + 边界 → 输出新变换（纯函数）。

## 备注

- 不用物理引擎做拖动，避免非确定性。
- 手势失败时状态必须复位（用更新态追踪）。
