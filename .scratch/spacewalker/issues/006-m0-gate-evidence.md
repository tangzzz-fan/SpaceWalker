## 背景

M0 的出口不是"感觉能跑"，而是六项可复核的证据。此 ticket 由人执行，agent 只准备清单与归档结构。

## 验收标准

- [ ] 6 项门禁逐项通过（与 PRD §11.2 一一对应）：会话启动、相机背景、平面锚定、能力探测、降级模式、权限错误态。
- [ ] 证据归档到 `docs/gates/M0/`：截图不少于 3 张、30 秒录屏 1 段、runtime log 1 份。
- [ ] 记录基准机型、系统版本、环境光照、测试人、日期。
- [ ] 已知问题清单（含复现步骤）与是否阻塞 M1 的结论。
- [ ] PRD §11.2 的 M0 条目逐条签字。

## 测试缝

无（人工门禁）。

## 备注

- 门禁未过不得开始 M1；超期 1 个迭代即触发方案评审。
- 证据文件不入 Git LFS 前，先确认体积；视频可只保留链接与关键帧。
