# 037 封神体系做实

## 起点

原来只有 28 条：靠「参宿四 → 参宿」的星官名反查，把二十八宿的封神名号挂到星官卡上。名号是真的，但体系是空的——用户查到「参水猿 · 孙祥」，不知道他属哪一部、管什么、还有谁和他同列。

第九十九回列了三百六十五位正神，八部十五门。这部分内容一直留在原文里，没有被用起来。

## 做法

### 一、全表录入

`tools/build-fengshen.py` 逐条录入第九十九回的具名者，输出 `Sources/Resources/fengshen.json`。脚本入库，数据可复核。

| 部 | 人数 | 说明 |
|---|---|---|
| 斗部 | 289 | 五斗星官 28、群星 115、二十八宿 28、天罡 36、地煞 72、九曜 9、斗母 1 |
| 雷部 | 25 | 雷祖闻仲 + 二十四天君 |
| 太岁部 | 12 | 殷郊、杨任 + 日直众星 10 |
| 瘟部 | 7 | 吕岳 + 四使 + 劝善、和瘟 |
| 痘部 | 7 | 余化龙、金氏 + 五方主痘 |
| 三山五岳 | 6 | 黄天化 + 五岳大帝 |
| 财部 | 5 | 赵公明 + 四神 |
| 四圣 / 四大天王 | 各 4 | |
| 三仙岛 | 3 | 云霄、琼霄、碧霄 |
| 火部 / 哼哈二将 | 各 2 | |
| 清福神 / 水部 / 分水将军 | 各 1 | |
| **合计** | **369** | |

三处与「365」不符的地方，按原文如实处理：

1. 二十八宿中尾、室、觜、翼兼火部，箕、壁、参、轸兼水部——原文「内有八人封在水、火二部管事，俱万仙阵亡」。这 8 人既算在二十八宿，也属水火二部职司，数据里用 `alsoServes` 标注，不重复计入部门人数。
2. 「闪电神」「助风神」原文只书名号不具名，据通行本补为金光圣母、菡芝仙，`note` 里注明。
3. 三百六十五是象征周天之数，原文实际列名多于三百六十五。

### 二、只有 43 位能落到天上

这一点必须先说清楚，否则「星榜」是空话。

369 条里，**只有 43 条能对应到星图上真实存在的星官**：

| 来源 | 人数 | 锚点 |
|---|---|---|
| 二十八宿 | 28 | `角宿`…`轸宿`，一官一人 |
| 北斗星官 | 9 | 全部锚到 `北斗` |
| 南斗星官 | 6 | 全部锚到 `斗宿` |

东斗 4、西斗 5、中斗 3 是道教五斗概念，中国传统星官体系里没有对应的官；群星 115、天罡 36、地煞 72、九曜 9 是虚构星名，天上找不到。这些条目仍然收录（「封神榜」的价值就在完整），但界面上标为不可定位。

于是界面上有「全部 369 / 可定位 43」这个分段控件。选「可定位」时只留 43 条，条条能跳到星图。

### 三、检索与定位

星榜从找星面板右上角的卷轴图标进入。三层结构：

```
封神星榜（八部十五门 + 人数 + 一句话职司）
  └ 斗部（部门说明）
      └ 五斗星官 · 28 位 / 二十八宿 · 28 位 / 群星 · 115 位 …
          └ 角木蛟 柏林   斗部 · 二十八宿    [角宿] 🎯
```

点带 🎯 的行 → 关闭星榜与找星面板 → 星图聚焦该星官 → 弹出分组卡。这条链路抽成 `SkyGroupIndex.group(forAsterism:in:)` 纯函数，单测锁住。

检索覆盖名号、人物、部门、分组、星官五个字段：「闻仲」→ 九天应元雷神普化天尊，「天魁星」→ 高衍，「斗部」→ 289 条。

### 四、星卡

`StarDisplay.fengshenLine` 改成数据驱动：

- 一官一人（二十八宿）：`封神 参水猿 · 孙祥`
- 一官多人（北斗）：`封神 9 位星君`

原来的「北斗七星君」是硬编码字符串，与新数据的九位不符，一并改掉。

## 验收

| 项 | 结果 |
|---|---|
| 条目 | 369，id 唯一 |
| 分组计数 | 群星 115、天罡 36、地煞 72、九曜 9、二十八宿 28、五斗 28、天君 24、日直 10、五方主痘 5，全部与原文对上 |
| 可定位 | 43，且每个锚点都能在 `asterisms.json` 里找到同名星官（单测断言） |
| 兼部 | 8 人，火部为尾/室/觜/翼，水部为箕/壁/参/轸 |
| 部门说明 | 15 个部门全部有 |
| 单测 | 251 项 0 失败（新增 7 项） |

模拟器实拍（31.251°N / 120.605°E）：

- 星榜首页：全部 369 / 可定位 43，八部依次列出
- 斗部：坎宫斗母 1 位 → 五斗星官 28 位 → 群星 115 位
- 搜「尾火虎」：`朱招 · 斗部 · 二十八宿 · 兼火部 · [尾宿] 🎯`
- 参宿分组卡：`封神 参水猿 · 孙祥`

## 调试入口

`SPACEWALKER_FENGSHEN` 接受三种值：

| 值 | 行为 |
|---|---|
| `1` | 打开星榜首页 |
| `斗部` | 直接进该部（部门名精确匹配） |
| `角木蛟` | 按关键词检索 |

模拟器是 headless，没有可点击的 UI，这个入口是唯一能验证「搜索 → 部门 → 定位」三层的方式；顺带也为将来做分享链接留了口子。

## 遗留

- 星卡上「封神 9 位星君」看不到具体名字。应当让这行可点，跳进星榜对应位置。
- 群星 115 位与天罡地煞 108 位只有名录，没有释义。若要做「水浒星名对照」（天罡地煞正是《水浒传》一百单八将的源头），是下一步可用的现成素材。
- 东斗、西斗、中斗三组共 12 人无处定位。若要落到星图，需另做「五斗」图层，与传统星官并列显示。
