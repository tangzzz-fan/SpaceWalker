## 背景

装配是拆解的逆过程，也是最容易被"物理手感"带偏的地方。基础定调：用规则判定，不用物理吸附；判定必须可单测、可复现。

## 范围

- 判定三条件：接口 ID 匹配、距离 ≤ 2cm、轴夹角 ≤ 5°。
- 通过后播放吸附动画（0.3s）并锁定；不通过时产生排斥反馈与一句原因。
- 错误接口 100% 拒绝。

## 验收标准

- [ ] 三条件同时满足才吸附，缺一不通过。
- [ ] 错误接口 100% 被拒绝，且有方向性排斥反馈。
- [ ] 吸附后模块位置与姿态锁定，不再受拖拽影响。
- [ ] 三模块全部复位后触发整体合拢动画。
- [ ] 判定为纯函数，至少覆盖：正确接口/错误接口/距离超限/角度超限。

## 测试缝

- 装配判定：输入模块变换 + 接口表 → 输出通过/失败原因（纯函数）。
- 吸附目标：输入接口与模块 → 输出目标变换（纯函数）。

## 备注

- **基础定调，后续可改**：2cm 与 5° 是默认阈值，M3 真机手感测试后可调。
- 物理只用于分离后的轻微漂浮（可选），不参与装配判定。
- 真机验收由 020 承接。
