## 背景

装配是拆解的逆过程，也是最容易被"物理手感"带偏的地方。
判定必须可单测、可复现、不依赖物理引擎的随机结果。

## 范围

- 判定三条件同时成立：接口 ID 匹配、距离 ≤ 2cm、轴夹角 ≤ 5°。
- 通过后播放吸附动画（0.3s）并锁定；不通过时按方向排斥 + 一句具体原因。
- 三模块全部装回后触发整体合拢动画。
- 判定与吸附目标都是纯函数，放在场景之外，可脱离 RealityKit 单测。

## 验收标准

- [x] 三条件同时满足才吸附，缺一不通过：`wrongPort` / `tooFar` / `badAngle` 各一条测试。
- [x] 错误接口 100% 被拒绝，排斥方向是单位向量且指向正确接口（`testRejectsWrongPort` / `testRejectsTooFar`）。
- [x] 吸附后位置锁定：`snap` 返回接口的绝对坐标，场景直接写死，后续拖拽从新位置起算。
- [x] 三类失败文案互不混淆，由 `Failure.message` 单一来源提供。
- [x] 容差边界可判定：0.99×容差通过、1.01×容差拒绝（`testToleranceBoundary`）。
- [x] 确定性：同一输入连跑 21 次结果一致（`testVerdictIsDeterministic`），判定里无随机、无物理。
- [ ] 合拢动画：未做，归 019（任务卡串起三步后才有「全部到位」的语义）。

## 实现记录

- `TiangongAssembly.verdict(module:at:angleDegrees:port:)` 是纯函数，不 import RealityKit。
- 拖动路径（主路径）：按在**已分离**的模块上 → 手势归模块，屏幕位移按投影焦距换成世界位移，松手即判定。
  按在空白处才是转相机；模式在按下时定一次，中途不切，否则拖到一半相机会跟着转。
- 排斥用 0.18s 的 `easeOut` 沿判定给的方向弹开 5cm，让「装不进去」有可见方向。
- **两条交互路径要分清**：
  1. 拖动 → 走完整三条件判定（本票的验收对象）。
  2. 卡片上的「装回」按钮 → 直接撤销分离，是便捷复位，**不参与判定的验收**。
- **UI 不可达的两种失败**：单接口模型下没有「错接口」可指，模块也不旋转所以「超角」不会发生。
  两者由纯函数测试覆盖，不在 UI 上造伪路径。
- `metersPerPoint` 用投影焦距而非线性近似，与 B 阶段准星口径一致；随距离线性缩放有测试。

## 测试缝

- 装配判定：输入模块变换 + 接口表 → 输出 `.snap` 或 `.reject(reason)`（纯函数）。
- 吸附目标：输入接口与模块 → 输出目标变换（纯函数）。
- 合拢条件：输入模块到位集合 → 输出是否合拢（纯函数）。

## 备注

- 2cm 与 5° 是展示尺度下的默认阈值，真机手感测试后可调，但调参只改常量不改判定结构。
- 物理不参与装配判定。
- 真机验收由 020 承接。
