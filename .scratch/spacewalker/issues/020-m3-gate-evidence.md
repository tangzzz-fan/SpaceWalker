## 背景

C 阶段的出口：三个任务可完整完成，失败原因准确，史实零错误。
C 阶段在虚拟视图验收——AR 入口目前黑屏未定性，不作为 M3 门禁项，也不阻塞本阶段。

## 验收标准

- [ ] C 阶段 P0 需求 100% 有验收记录（FR-C-01..05）。
- [ ] 拆解、装配、对接三个任务可完整完成，各录屏 1 段。
- [ ] 四类对接失败均可复现（过快 / 偏角过大 / 撞偏 / 超时），原因文案与判定输出一致。
- [ ] 史实核对表逐条签字，字段与 `docs/research/realitykit-ios26-primary-sources.md` 第 15 条一致；
      全局文案扫描无「空间站」。
- [ ] 辨识度记录：062 的四视角截图与判定结论一并归档。
- [ ] 帧率满足 NFR-01 的 C 阶段口径（平均 ≥ 25fps、下限 20fps），真机 60 秒连续运行。
- [ ] 证据归档到 `docs/gates/M3/`。
