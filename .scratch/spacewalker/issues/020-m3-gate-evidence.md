## 背景

C 阶段的出口：三个任务可完整完成，失败原因准确，史实零错误。

## 验收标准

- [ ] C 阶段 P0 需求 100% 有验收记录。
- [ ] 拆解、装配、对接三个任务可完整完成，各录屏 1 段。
- [ ] 四类对接失败均可复现，原因文案与判定输出一致。
- [ ] 史实核对表逐条签字，界面无"空间站"称谓。
- [ ] 帧率满足 NFR-01 的 C 阶段口径（平均 ≥ 25fps、下限 20fps）。
- [ ] 证据归档到 `docs/gates/M3/`。

无（人工门禁）。

## 备注
