## 背景

C 阶段的核心玩法：控制神舟飞船靠近天宫一号对接口，在容差内完成对接。
这是"看得懂、做得到、失败得起"的任务，也是 M3 三条 KR 里唯一靠手感成立的一条。

## 范围

- 六自由度输入：单指拖动 = 横/纵向平移；双指捏合 = 轴向推进/后退；
  双指旋转 = 俯仰/偏航微调；长按 200ms = 粗调/精调切换。
- 设备姿态微调是 P1：有陀螺仪才给，没有就隐藏（同 B 阶段 `canFollowAttitude` 的处理）。
- 成功条件（展示尺度，需持续 1 秒）：接近速度 ≤ 0.02m/s、轴向偏差 ≤ 2cm、
  姿态偏差 ≤ 5°、角速度 ≤ 5°/s。
- 四类失败：过快、偏角过大、撞偏（接触时超差）、超时（90 秒）。
- 失败后可一键重试，不退出场景。

## 验收标准

- [ ] 五个自由度均可独立生效（平移 2 + 轴向 1 + 俯仰偏航 2），粗调/精调切换有明确反馈。
- [ ] 成功路径可复现：同一操作序列两次运行结果一致。
- [ ] 四类失败均可稳定触发，各给出对应原因文案，且原因与判定输出同源（不另写文案）。
- [ ] 容差边界可判定：刚好在阈值内成功、刚好超出失败，各有测试。
- [ ] 失败后一键重试，飞船回到初始位姿，任务计时归零。
- [ ] 判定与输入映射都是纯函数，可脱离 RealityKit 单测。

## 测试缝

- 对接判定：输入相对位姿/速度/角速度/持续时间 → 输出成功或失败原因（纯函数）。
- 输入映射：输入手势增量 + 粗调精调模式 → 输出六自由度增量（纯函数）。
- 容差边界：参数化测试，阈值两侧各取点。

## 备注

- 0.02m/s、2cm、5°、5°/s、90s 均为默认值，真机试玩后可调常量，判定结构不变。
- 若手感不成立，按 ADR-0002 退化为引导式对接（提示"再近一点/角度偏左"），不延长工期。
- 真机验收由 020 承接。
