## 背景

C 阶段的核心玩法：控制神舟飞船靠近天宫一号对接口，在容差内完成对接。这是"看得懂、做得到、失败得起"的任务。

## 范围

- 六自由度输入：单指拖动 = 横/纵向平移；双指捏合 = 轴向推进；双指旋转 = 俯仰/偏航；长按 = 粗调/精调；设备姿态 = 姿态微调。
- 成功容差（1:20 展示尺度）：接近速度 ≤ 0.02m/s、轴向偏差 ≤ 2cm、姿态偏差 ≤ 5°、角速度 ≤ 5°/s、保持 1s。
- 失败原因：过快、偏角过大、撞偏、超时（90s）。

## 验收标准

- [ ] 六自由度输入均可独立生效，粗调/精调切换有明确反馈。
- [ ] 成功路径可复现：同一操作序列两次结果一致。
- [ ] 四类失败均可触发，并给出对应原因文案。
- [ ] 失败后可一键重试，不需要退出场景。
- [ ] 判定为纯函数，覆盖成功与四类失败。

## 测试缝

- 对接判定：输入相对位置/姿态/速度/角速度/持续时间 → 输出成功或失败原因（纯函数）。
- 输入映射：输入手势增量 + 当前模式 → 输出六自由度增量（纯函数）。

## 备注

- **基础定调，后续可改**：0.02m/s、2cm、5°、5°/s、90s 均为默认值，M3 真机试玩后调整。
- 若手感不成立，按 ADR-0002 退化为引导式对接，不延长工期。
- 真机验收由 020 承接。
