## 背景

FR-C-07 的 L0 层要求剪影与参考图一致。当前 015 的几何有三处结构性错误（v0.10 审核）：

1. 实验舱是一整段 4.8 m 圆柱直接落到 Ø2.775 的资源舱，**缺后锥段**——参考图上这里是一个收细过渡，
   一手文字也说实验舱由「前锥段 + 圆柱段 + 后锥段」组成。
2. `TiangongMesh.frustum` 只能生成直母线，返回舱被做成锥台，读成「锥」而不是「钟」。
3. 所有段都是端面对端面拼接，改装后容易出现缝隙或 z-fighting。

## 范围

- 新增 `TiangongMesh.revolve(profile:segments:)`：输入 `[(radius, y)]` 折线，输出旋转体；
  `frustum` 保留为它的两段特例（调用方不改）。
- 实验舱重分段（**视觉分配，不是史实**，不进信息卡）：
  - 前锥段 1.6 m（Ø3.35 → 0.42R，朝 +Z 接对接环）
  - 圆柱段 4.0 m
  - 后锥段 0.8 m（Ø3.35 → Ø2.775，接资源舱）
- `shenzhouCapsuleLength` 的返回舱改用 revolve，母线取 4–6 个控制点做钟形外扩。
- `TiangongLayout` 补 `labRearConeCenter`，`labSealLength` 由 4.8 改为 4.0。

## 验收标准

- [ ] `labConeLength + labSealLength + labRearConeLength == labLength`（6.4 m）。
- [ ] 相邻段端面半径差 = 0（前锥↔圆柱、圆柱↔后锥、后锥↔资源舱）。
- [ ] 整机全长仍为 10.4 m，`footprint` 不越 1.0。
- [ ] 返回舱 revolve 的母线单调：半径随 z 单调不减，无自交。
- [ ] 既有 310 项测试**零改动通过**（尤其装配判定与对接判定不得因 `dockingPortZ` 变化而偏移）。
- [ ] 模拟器截图：侧视能看到三段分界，无缝隙、无 z-fighting。

## 测试缝

几何参数与母线都是纯值，可断言：分段和、端面半径连续性、母线单调性。
渲染缝隙不可自动化，靠侧视截图人工核。

## 备注

- 改分段会移动 `labCenter` / `dockingPortZ` / `shenzhouCenter`。这三者被装配判定与对接判定引用，
  必须先在测试里锁住"整机包围盒中心"与"对接口 z"，再改几何，否则会连带改掉玩法参数。
- 顺序：本票必须先于 065/066/067——贴图贴在错的分段上等于白做。

## 实现记录

**结果**：`dockingPortZ` 保持 0.36 未变（`testDockingPortZIsPinned` 锁住），装配与对接判定零改动。

- `TiangongMesh.revolve(profile:height:sides:caps:)`：母线 (半径, 轴向比例)，法线按相邻母线段的切线解析求出，
  平滑过渡。`frustum` 退化为两点特例的包装，调用方签名加了一个 `caps` 默认参数。
- 实验舱拆成 6.4 = 后锥 0.8 + 圆柱 4.0 + 前锥 1.6，局部偏移由 `labRearConeOffset` / `labCylinderOffset` /
  `labConeOffset` 三个纯值算出，`labCenter` 改为整段中点（0.16）。
- 返回舱改用七点母线，窄端 0.72R 与轨道舱 0.74R 衔接。

**两个真 bug（都是渲染时才暴露、单测抓不到的）**：
1. **母线坐标顺序反了**：数据写成 `(t, r)`，`revolve` 按 `(r, t)` 读。症状是返回舱半径全落在 0…1 之间、
   细到看不见。**被 `testCapsuleProfileShrinksMonotonically` 抓到**——这是写断言而非只看截图的直接收益。
2. **端面法线用了侧面的**：端盖三角扇在中心法线与环法线之间插值，渲染出来是一圈星芒。修法是端盖另起一组
   顶点、法线统一为 ±Y。
3. **共面封盖 z-fighting**：锥段与相邻圆柱的端盖落在同一平面，出现放射状锯齿。加 `Caps` 枚举，贴合端留空
   （由邻件的封盖负责封闭）。这条在截图上极易被误判成"破面"，本质是深度冲突。

**验证**：318 项测试 0 失败（新增 8 项）。其中 `TiangongSceneSegmentationTests` 直接量四个子件的轴向区间，
断言首尾相接误差 < 0.2 mm——比截图更硬，不依赖光照。分离态`pick ok=4/5` 与改造前一致。

**遗留**：默认视角比 M3 门禁截图偏暗。原因不是几何：白 MLI 用了 `isMetallic: true`，在星系天空盒这种
暗环境下金属度 1.0 基本等于"照一面黑墙"。属于 066 的材质分层，本票不动。
