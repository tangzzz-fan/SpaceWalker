# M2-028 星座轮廓与封神名号

## 背景

连线能看出骨架，但看不出「轮廓」；用户点名要看大熊座那样的外轮廓。另希望把《封神演义》的星宿神位做成趣味层。

## 范围

### 1. 星座轮廓

- 每个星座生成一个闭合外轮廓：**有手工环的用手工环，没有的用凸包**。
- 手工环 6 个（按图形走势排定星序，非凸）：
  - 猎户座：参宿四 → 参宿五 → 参宿三 → 参宿七 → 参宿六 → 参宿一（沙漏）
  - 大熊座：Alkaid → Mizar → Alioth → Megrez → Dubhe → Muscida → Tania Borealis → Tania Australis → Phecda
  - 仙后座：Caph → Schedar → Cih → Ruchbah → Segin（W 形闭合）
  - 天鹅座：Deneb → Aljanah → Sadr → Fawaris → Albireo（十字闭合）
  - 天琴座：Vega → Sheliak → Sulafat（三角）
  - 南十字座：Gacrux → Mimosa → Acrux → Imai（菱形）

  注：无确认中文名的星用拉丁名，不臆造星官名。
- 渲染两层，挂在 `constellationGroup` 下随「星座」开关一起显隐：
  - 填充：球面扇形三角化，半径 51.4（在星点之后），近黑深蓝 `#0A0F1D`，硬边不透明。
  - 描边：沿轮廓环的细柱，半径 0.011，冷蓝 `#6677BF`，比连线更细更暗。
- draw call：连线 1 + 填充 1 + 描边 1 = 3（原为 1），总额 9，仍在 FR-B-01 的 ≤10 预算内。

### 2. 封神名号

- 数据据《封神演义》第九十九回姜子牙封神：28 宿星君名号 + 人物名。
- 其中 8 人另封水、火二部：火部（尾火虎朱晤、室火猪高震、觜火猴方贵、翼火蛇王蛟）、水部（箕水豹杨真、壁水貐方吉清、参水猿孙祥、轸水蚓胡道元），界面加部门徽标。
- 星卡新增一行：`封神 参水猿 · 孙祥`；北斗七星显示 `封神 北斗七星君`。
- 星座面板新增「封神」栏目，按该星座实际含有的宿去重列出。
- 脚注注明出处与「各版本人名偶有出入」（参水猿一作孙宝）。

## 验收

- [x] 单测：28 宿名号齐全；水火二部各 4 人且宿名正确。
- [x] 单测：`参宿 → 参水猿/孙祥`；`五车` 不误匹配。
- [x] 单测：星卡文案（参宿四、天枢）。
- [x] 单测：6 个手工轮廓引用的星名都存在于星表，且至少 3 个点。
- [x] 单测：多边形扇形顶点/索引数与半径；凸包剔除内部点。
- [x] 模拟器：猎户座呈上下两个三角形相接的沙漏填充，不再是外接四边形（截图）。
- [x] 模拟器：猎户座面板底部出现「封神 参水猿 孙祥 水部」（截图）。
- [ ] 真机：轮廓在转动时贴合星点、不抖动；填充不遮挡星点。
- [ ] 真机：draw call 与帧率实测。

## 已知边界

- 只有 6 个星座有手工环，其余 25 个仍是凸包，形状是外接多边形，不等于传统图形。
- 手工环只按星表内专名星排定，未引入星图插画的贝塞尔曲线，因此是「多边形轮廓」而非「熊形插画」。
- 封神人物名以《封神演义》通行本为准，不同版本有出入，已注明。
