# 036 补全 88 星座释义

## 背景

原有 31 条释义，正好对应 31 个有连线的星座。其余 57 个星座点开只有一句「这个星座在本版本还没有收录释义」。

## 做法

按 IAU 88 星座逐个补 `westernLore` 与 `chineseLore`，共 88 条。

写作原则：

1. **西方来头写来源，不写形容词**。希腊神话给具体人物与因果（伽倪墨得斯被鹰叼上奥林匹斯），16–17 世纪新设星座给设座者与命名缘由（拉卡伊的气泵、海维留斯的盾）。
2. **中国星官宁缺毋滥**。有确切对应的写具体星官（宝瓶座跨女、虚、危三宿，含「羽林军」「坟墓」）；南天深空那批中国传统星表确实少有命名，统一写「南天深空，中国传统星表在此基本没有命名星官」，不硬套。
3. **有一个算一个的具体锚点**：能说出「危宿一与虚宿一分别是它的 α、β 星」「北落师门以它上中天定秋分」就不写空话。

三条南天星座无法对应星官（蝘蜓、南极、山案），措辞用「南天深处」，与「南天深空」区分开。

## 质量控制

既有单测 `testStoriesAreNonEmpty` 要求：西方来头 > 20 字、中国星官说明 > 15 字。首轮写完有 32 条不达标，逐条补写到位（多是南天小星座的中国段太短，或拉卡伊设座那句只有十几个字）。

新增两条测试：

- `testEveryConstellationHasLore`：88 个 IAU 缩写逐一查，两段都不能为空
- `testLoreLengthIsReadable`：上限约束，防止写成大段（> 90 字反而读不下去）

同时修了一条旧断言：`testEveryDrawnConstellationHasStory` 原来要求「释义数 == 有连线星座数」，补全后必然失败。改成「释义里的缩写必须是真实星座」，允许释义多于连线。

## 验收

- [x] 88 条，键与 `abbreviation` 一一对应
- [x] 每条两段均非空，长度在 20–90 / 16–90 之间
- [x] 宝瓶座实拍：跨女、虚、危三宿，含「羽林军」「坟墓」
- [x] 244 项单测 0 失败

## 遗留

- 南天星座的中国段是「尚未命名」的如实说明，仍显单薄。若要更实，需查《仪象考成》等清代星表对南天的增补（如「南船」「十字架」等，部分有清代译名）。
