# 029 星座图形轮廓（熊 / 蝎 / 狮）

## 目标

把「外接多边形」升级成能认出来的动物轮廓，只做有公认传统形象的星座，不追求全覆盖。

## 数据来源与许可

社区排查结论（2026-11-07）：

| 来源 | 内容 | 许可 | 可用性 |
|---|---|---|---|
| d3-celestial | 星座连线 | BSD-3 | 已有同类数据 |
| Stellarium `constellationsart` | 星座美术图（Johan Meuris） | Free Art License（copyleft） | 不可用于闭源分发 |
| Stellarium `constellationship.fab` | 连线 | GPLv2+（作者讨论区口头授权） | 法律上不干净 |
| Hevelius / Bode 星图 | 版画 | 公有领域 | 位图，需自行按星表配准 |

结论：没有可直接使用的「已配准矢量剪影」数据集。图形按**星表坐标自行配准**，造型参照公有领域星图的通行画法，不使用上述 copyleft 素材。

## 实现

- `ConstellationFigure`：锚点星名 + 若干归一化环（x=东，y=北，取值约 [-1.2, 1.2]，由锚点星包围盒归一化）。
- `ConstellationFigureBuilder`：锚点求球面质心 → 东/北切平面基 → 每颗锚点星投影为局部度 → 取包围盒 → 归一化点先转局部度，再指数映射回单位球。
- 凹多边形用耳切三角化（`StarFieldBuilder.triangulate`），替换原来的质心扇形；扇形在凹轮廓上会产生越界三角形。
- 每个环同时生成填充（半径 51.4）与描边（半径 50.6，细柱 0.011）。

## 覆盖

| 星座 | 环数 | 形状 |
|---|---|---|
| UMa 大熊 | 1（44 点） | 侧视熊：吻、耳、背、长尾、前后腿 |
| Sco 天蝎 | 5（头 + 两螯 + 躯干条 + 尾端球） | 弯钩尾与螯 |
| Leo 狮子 | 1（33 点） | 侧视狮：头、身、两腿、尾尖到五帝座一 |

其余星座保持手工环（猎户沙漏、仙后 W、天琴三角、南十字菱形）或凸包。

## 验收

- [x] 每个锚点星都落在图形内（`isInside` 单测，209 项全绿）
- [x] 归一化与方向互逆（往返误差 < 0.02）
- [x] 凹多边形三角化：三角形数 = n-2，面积和 = 鞋带面积
- [x] 模拟器：`SPACEWALKER_AIM=UMa|Sco|Leo` 截图确认填充与描边
- [ ] 真机：转动时轮廓无抖动、无 z-fighting
