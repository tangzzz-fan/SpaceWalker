# 030 落点从单颗星扩到星官 / 宿 / 星座

## 结论

可做，且数据层已具备：中文星名表按「星官 + 序号」解析后，可得 81 个星官组（27 组 ≥2 颗），
其中 20 个二十八宿能直接对上星官名；另有 31 个星座与 4 个经典组合。

## 语义规则（避免误触）

| 场景 | 规则 |
|---|---|
| 准星停在星上 | 出星卡，不出组卡（星优先） |
| 搜索/列表选中组 | 定位到组心 + 出组卡 |
| 一颗星属多个组 | 卡片并列归属，不做唯一归属 |
| 北斗 与 北斗七星 | 成员被星官完全覆盖时丢弃组合，另加查询别名 |

## 实现

- `SkyGroup`：id / kind（宿、星官、星座、组合）/ 标题 / 成员 / 封神名号。
- `SkyGroupIndex`：分组、四路检索（标题、封神名号、人物、成员中文名）、组心、最亮、成员列表。
- 组心 = 成员单位向量均值；`SkyScene.aim(at:)` 把该方向转到视野中心。
- 组卡：标题 + 类型徽标 + 封神行 + 最亮星 + 成员胶囊（点击下钻到单星）+ 指路按钮。
- 调试：`SPACEWALKER_GROUP=参宿`、`SPACEWALKER_QUERY=参水猿`。
