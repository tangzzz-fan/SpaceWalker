# 047: 候选查询以方向为单位

**What to build:** 让场景能回答「朝这个方向看有什么可选中」，而不是只能回答「屏幕这个点命中了什么」。当前的点环取中心方向调用它；B 阶段的视锥选中取视锥内的若干方向调用同一个入口。触摸点选保留原路径，手感不变。
