## 背景

PRD 的 FR-X-06（一键重置）与 FR-X-03（会话中断恢复）在 M1 必须有落点，否则 M1 门禁的"A 阶段 P0 全过"无法成立。

## 验收标准

- [ ] 一键重置：布局、选中态、时间轴、缩放全部回到初始，与首次放置一致。
- [ ] 重置不重置权限与能力状态，不重启会话。
- [ ] 会话中断（来电/锁屏/切后台）恢复后，已调参数与选中态保留。
- [ ] 连续重置 3 次无状态残留、无内存增长异常。
- [ ] VoiceOver 可触发重置并听到结果提示。

## 测试缝

- 重置状态机：输入当前应用状态 → 输出重置后的状态（纯函数）。
- 恢复合并：输入中断前状态与恢复事件 → 输出合并后状态（纯函数）。

## 备注

- 真机验收由 011 承接。
- 不使用"重建整个场景"实现重置，避免会话重启导致锚点丢失。
