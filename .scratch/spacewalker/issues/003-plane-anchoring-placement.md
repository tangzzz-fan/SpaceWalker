## 背景

M0 的关键路径：把虚拟内容稳定地放到真实桌面上。本 ticket 只放一个占位立方体，验证"找平面 → 显示准星 → 点击放置 → 保持不动"。

## 验收标准

- [ ] 检测到水平面后显示落点准星；平面不足时提示"移动手机扫描桌面"。
- [ ] 轻点放置占位立方体，立方体底面贴合平面，不悬浮、不穿地。
- [ ] 木质桌面与地板各成功放置 3 次，放置点与点击点偏差 < 5cm。
- [ ] 绕桌走一圈，立方体相对桌面的偏移 ≤ 20cm（NFR-10）。
- [ ] 遮挡相机 5 秒后恢复，出现"重新放置"提示，可一键重放。

## 测试缝

- 落点解算：输入射线与平面 → 输出世界坐标与法线（纯函数）。
- 漂移判定：输入两次相机位姿与锚点位姿 → 输出是否超限（纯函数）。

## 备注

- 锚点优先用平面锚定，不用纯世界锚点。
- 记录首次锚定耗时，作为 NFR-02 的分解指标；判定口径以 PRD 为准。
