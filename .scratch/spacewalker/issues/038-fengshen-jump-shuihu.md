# 038 封神人物跳转与天罡地煞

## 一、星座轮廓的现状（先答问题）

31 个有线星座**全部有填充轮廓**，但质量分三档：

| 档 | 数量 | 做法 | 观感 |
|---|---|---|---|
| 美术图形 | 3 | 手工描点环，认得出动物 | 大熊（44 点周身 + 尾）、天蝎（5 环：头、双螯、身、尾钩）、狮子（33 点头鬃到后腿） |
| 手工星点环 | 5 | 按真实亮星连成闭合折线 | 猎户、仙后、天鹅、天琴、南十字 |
| 凸包 | 23 | `hullRing()` 自动求凸包 | 一块包住所有星的多边形色块，**看不出形状** |

所以对「知名星座」这个标准，答案是**没有完成**：8 / 31 有形状。缺的正是最常被认的那几个——金牛、双子、飞马、牧夫、大犬、小熊、天龙、室女、人马、摩羯。

补齐的成本不在代码：`hullRing` 之上的 `ConstellationFigure` / `outline` 两条路径都已就绪，缺的是每个星座一组按真实亮星排的闭合星点序列。金牛的 V 形脸加双角、飞马的方形躯干加前腿、牧夫的风筝、人马的茶壶，都是可以先画的；再往下（天龙的多折、室女的不规则边界）收益递减。

## 二、封神人物跳转

原来封神数据是单向的：星图 → 星榜（点星君定位星官）。反向没有入口——用户在星卡上看到「封神 参水猿 · 孙祥」，想知道这人是谁、管什么、和谁同列，无处可去。

补上反向：

```
星卡 / 分组卡「封神 参水猿 · 孙祥」  →  星榜 → 自动进斗部 → 滚到该条并高亮
```

实现三处：

1. 星卡与分组卡的封神行由 `Text` 改为 `Button`，带卷轴图标与 chevron，提示可点。
2. `FengshenBoardView` 加 `focusAsterism`：进入时按该星官的第一位星君推出部门，压入导航栈。
3. `FengshenDepartmentView` 加 `highlight: Set<String>`，命中的行加浅色底，`ScrollViewReader` 滚到该行。

北斗这类一官九人的情况整组高亮——`focusAsterism: "北斗"` 命中 9 条，进斗部后直接看到九位大字排开。

## 三、天罡地煞与一百单八将

《水浒传》的一百单八将星号，直接取自第九十九回随斗部的天罡三十六与地煞七十二，**座次即封神榜上的次序**。

| 项 | 数值 |
|---|---|
| 对照条数 | 108（36 + 72） |
| 两书星名相同 | 101 |
| 写法不同 | 7 |

七处差异：

| 封神 | 水浒 |
|---|---|
| 天玄星 | 天立星 |
| 天健星 | 天捷星 |
| 天煞星 | 天杀星 |
| 地辅星 | 地轴星 |
| 地祐星 | 地佑星 |
| 地默星 | 地然星 |
| 地魂星 | 地丑星 |

数据里两者都保留：`title` 存封神原名，`shuihu.star` 存水浒写法。界面以水浒为准，行内标「封神作 天玄星 · 王龙茂」，顶部列出全部七处。

### 呈现

- 星榜首页新增「一百单八将」入口
- 独立页按座次 1–108 列出：座次、星号、绰号、姓名，下方小字标封神原名
- 星榜里天罡、地煞两组的每一行也带上「水浒 1 · 呼保义 宋江」标签
- 检索扩到绰号与梁山姓名：「宋江」「黑旋风」「段景住」都能直接命中

## 验收

| 项 | 结果 |
|---|---|
| 对照 | 108 条，座次 1…108 连续，无缺号无重复 |
| 首尾 | 1 宋江、108 段景住 |
| 差异 | 7 处，集合精确匹配 |
| 检索 | 宋江 → 1、黑旋风 → 李逵、段景住 → 108 |
| 单测 | 254 项 0 失败（新增 3 项） |

模拟器实拍：一百单八将首页、从「北斗」跳转后斗部九星高亮。

## 遗留

- 一百单八将页不可点进封神星君详情（星君无星官可定位，点进去也只能看文字）。
- 轮廓补齐仍是最显眼的内容缺口，见第一节。
