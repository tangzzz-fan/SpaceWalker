# M2-026 星座来头与当前天区

## 背景

星座连线能让人「看出形状」，但看不出「这是什么、有什么来头」。本票补一层知识：看向哪片天，就告诉你是哪个星座、西方与中国两套体系怎么讲它。

## 范围

### 1. 天区识别

- `ConstellationInfo.nearest(to:in:)`：以视线方向找最近的成员星，取该星星座。2996 颗全量参与，0.5s 节流。
- 明确标注这是**近似**：不是 IAU 边界多边形，稀疏天区可能偏到邻近星座。卡片显示「距最近成员星 N°」。

### 2. 知识文案

- 88 个星座的中文名 + 拉丁名 + 三字母缩写（`ConstellationNames` / `ConstellationInfo.latinNames`）。
- 31 个有连线的星座各两条释义：`westernLore`（希腊神话/现代由来）、`chineseLore`（对应星官、所属宿与四象、文化含义）。
- 其余 57 个星座不做杜撰，仅展示星表统计（星数、最亮星、最佳观测月）。

### 3. 派生统计（不靠手填，从星表算）

- 星数、最亮星（按视星等）。
- 最佳观测月：成员星单位向量求质心 → 平均赤经 → `月 = (9 + RA/2) mod 12`，与「子夜上中天」一致（猎户座 → 1 月，天蝎 → 7 月）。

### 4. 入口

- 顶部「当前天区 猎户座 · 查看来头」→ 知识面板。
- 找星面板 → 按星座 → 该星座页顶部直接展示两段来头。
- 面板底部「指路到 参宿七」直接复用手指路模式。

## 验收

- [x] 单测：31 个有连线的星座与 31 条文案一一对应，无缺无多。
- [x] 单测：两条文案长度下限（防占位符混入）。
- [x] 单测：`region` 最亮星、星数、最佳观测月、中文名（猎户座 → 参宿七 / 2 颗 / 1 月）。
- [x] 单测：`nearest` 指向参宿四得到 Ori，指向心宿二得到 Sco。
- [x] 单测：88 个星座缩写都有拉丁名（对星表全量校验）。
- [x] 模拟器：面板显示「猎户座 Orion Ori / 星表内 76 颗 · 最佳观测 1 月 / 最亮星 参宿七 0.18 / 可选中 10 颗」+ 两段来头 + 星官 chips + 指路按钮（截图）。

## 已知边界

- 天区识别是最近成员星近似，银河带等稀疏区可能判到邻近星座，卡片已注明距离。
- 57 个冷门星座没有释义文案，属数据缺口而非渲染问题。
- 来头文案为科普性概述，不作学术引用依据。
