# 060 星官目录：按四象二十八宿浏览

- 日期：2026-11-07
- 状态：完成
- 关联：058（culture 档）、059（星官卡）

## 一、为什么

059 让星官「能识别」，但找星官仍只能靠搜索。301 个星官没有目录，等于一本没有目录的书。

## 二、分组依据

用**四象二十八宿**——这是标准划分，每象七宿、顺序固定，不需要编造：

| 象 | 七宿 |
|---|---|
| 东方苍龙 | 角 亢 氐 房 心 尾 箕 |
| 北方玄武 | 斗 牛 女 虚 危 室 壁 |
| 西方白虎 | 奎 娄 胃 昴 毕 觜 参 |
| 南方朱雀 | 井 鬼 柳 星 张 翼 轸 |

其余 273 个星官进「其他星官」，按成员星数降序、同数按名字，**顺序稳定**——目录不能每次打开都变。

三垣（紫微/太微/天市）没有做：数据里没有这个字段，硬编码 76 个官名等于自己造数据，不做。

## 三、入口与交互

底栏「星官」由按钮改成菜单：显示星官连线 / 浏览星官。选中一行 → 复用 `SkyGroupIndex.group(forAsterism:)` 定位并关页。

## 四、验证

- 327 项测试 0 失败。新增两条：四象 28 宿不重不漏且与星表一致；目录分区覆盖全部 301 个星官、首段为东方苍龙 7 条、末段为其他星官。
- 截图：东方苍龙下 7 条，房宿显示「4 星 · 3 线段 房日兔 · 姚公伯」——059 里验过的 43 条可定位数据在这里直接可见。
- `SPACEWALKER_ASTERISMS=1` 可开机直开目录，供无头截图。
