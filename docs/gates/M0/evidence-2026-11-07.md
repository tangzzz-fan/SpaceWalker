## 已知限制与待办

- `devicectl process launch --console` 捕获不到 `os.Logger` 与 `NSLog` 输出，运行时日志目前只能靠 DEBUG HUD 截图；005 需要另找通道（如 Console.app 或 `log collect`）。
- 655ms 是"启动 → `run` 返回"，不等于"首帧上屏"。NFR-02 的 1.0s 需用录屏逐帧计算，尚未测。
- 生命周期项（前后台、来电、锁屏、退出释放）必须人工操作，agent 不代为判定。
- 切换入口：`SPACEWALKER_MODE=prototype` 启动进原型，缺省进会话骨架。
