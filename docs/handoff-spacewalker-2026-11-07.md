### 6.2 判断：精细化和 062 是同一件事

062 的盲测结论是「裸看像水管」，补偿手段是**常驻 5 个标签**。
但标签解决的是「这是哪一段」，不解决「这是什么」——用户第一眼仍然认不出。
把 ①–⑦ 补上，剪影与分块就足以自证身份，标签可以从「常驻」降为「选中显示」。
换句话说：**精细化不是给已经成立的东西加面数，而是把 062 的降级方案往回买。**

## 8. 精细化四层（施工口径）

预算：实体 ≤ 60、三角形 ≤ 20k、draw call ≤ 40；NFR-01 C 阶段（平均 ≥ 25fps）不放宽。
**只改 `addLab / addResource / addWing / addShenzhou` 内部**，不动 `TiangongSession`、
判定纯函数与任务状态机——现有 310 项测试应当零改动通过，新增测试只测几何预算与结构断言。

| 层 | 内容 | 手段 | 可测断言 |
|---|---|---|---|
| **L0 结构** | 后锥段 0.8 m（6.4 拆成 4.0 + 1.6 + 0.8）；神舟返回舱改母线旋转体；翼分 4 格 | 新增 `revolve(profile:)`（现有 `frustum` 是它的特例） | 分段长度和 = 6.4；相邻段端面半径差 = 0；每翼格数 = 4 |
| **L1 分块** | 加强环 ×3、纵向板缝、舱门舷窗、对接机构环 + 4 卡爪、翼根斜撑 | `MeshDescriptor` 直出 + 少量 `generateBox` 合并成单 mesh | 每模块子件数 ≥ 3；对接机构子件 ≥ 3 |
| **L2 材质** | 程序化贴图（接缝 / 电池片网格 / 噪声）；白 MLI、金箔、电池片三档；背后补一盏冷轮廓光 | `CGContext` 画图 → `TextureResource`（复用 `SpaceEnvironment` 的 CGImage 路线） | 材质档 ≥ 3；贴图只生成一次并缓存（`rebuild()` 不复建） |
| **L3 小件** | 主发动机 ×2 + 备用 ×4 + 姿控喷口；Ø1 m 抛物面天线；推进舱发动机 ×4；舷窗 | `revolve` 生成喷管与抛物面 | 实体 ≤ 60；三角形 ≤ 20k |

顺序：L0 → L1 → L2 → L3，每层一票一提交；L2 是观感跳变最大的一层，但必须排在 L0 之后，
否则贴图会贴在错的分段上。
