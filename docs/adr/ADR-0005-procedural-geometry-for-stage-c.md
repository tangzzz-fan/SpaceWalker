# ADR-0005：C 阶段用程序化几何加细节，不引入外部 3D 资产

- 状态：已采纳（2026-11-08）
- 取代：无（结案 PRD Q2「C 阶段美术方案」）
- 关联：PRD v0.10 §7.4 FR-C-07、§11.2 M3.1、§11.4 X-07/X-08；ticket 015 / 062 / 064–068

## 背景

015 用 `MeshResource.generateCylinder` / `generateBox` / 自写 `frustum` 搭出五个模块，536 三角形。
062 拿它做实体表达盲测，结论是**不通过**——裸看像「两段圆筒 + 两片薄板 + 一个锥」。
当时采用降级方案：示意模型 + 5 个常驻标签，把辨识责任交给文字。

PRD Q2 写的是「程序化材质，M3 前再评估是否升级」。M3 已签发，这条债到期了。
用户随后明确要求「天宫一号做精细些」，于是必须回答一个二选一：

- 换外部资产（USDZ / Blender / 外包），把"精细"交给雕刻；
- 继续程序化，把"精细"交给**结构正确 + 分块 + 材质 + 小件**。

## 决策

继续程序化，按 L0–L3 四层加细节；**不引入 USDZ、不引图片贴图、不外包**。

## 理由

1. **问题不在雕刻，在结构。** 对照参考图逐条核，缺的是后锥段、翼分格、对接卡爪、尾部动力系统、钟形母线——都是"少了零件"，不是"做得不够细"。这类缺口用几何参数就能补，用雕刻反而补不准。
2. **面数不是瓶颈。** 现在 536 三角形跑 59.9fps（真机 70 秒实测），NFR-01 的 C 阶段只要 25fps。预算给到 20k 仍有近 800 倍余量。
3. **外部资产要重新切分。** 五个模块必须能独立移动（拆解 FR-C-02、装配 FR-C-03、对接 FR-C-04）。拿到一个整机 USDZ 也要按接口切五份，切分成本抵消掉建模收益，还多一层坐标对齐风险。
4. **资产管线引入四类新风险**：许可（CC 协议混用）、包体（NFR-09 <80 MB）、版本漂移（二进制不可 diff）、贴图尺寸。程序化路线这四项全为零。
5. **可测性。** 结构能断言（分段和 = 6.4 m、端面半径连续、每翼 4 格、实体/三角形预算），雕刻不能。门禁需要可复现的判据。

## 后果

正面：

- 零外部资产，包体不变，仓库不增长二进制。
- 几何参数集中在 `TiangongModel`，改一个数字全场景跟着变。
- 结构断言进单测，回归时能拦住"改细节把比例改坏"。
- 贴图用 `CGContext` 画成 `CGImage` 再转 `TextureResource`，与 `SpaceEnvironment` 的既有路线一致。

负面：

- 达不到照片级写实。目标要写清楚：**"经得起近看的技术展示"，不是"以假乱真的复原"**。
- 程序化贴图的表现力有限（板缝、网格、噪声可以，掉漆、烧蚀、褶皱不行）。
- 小件越多，`rebuild()` 的构建成本越高。当前五个实体可忽略，60 个实体需要实测一次进入耗时。

## 解除条件

同时满足才重新评估 USDZ：

1. M3.1 盲测连续两轮 < 3/5；
2. FR-C-07 的结构清单**已无缺项**（即不再是"少了零件"）。

两条同时成立，才说明瓶颈确实转移到了雕刻，那时换资产才划算。
