设计说明

语义

「星槎」出自晋·张华《博物志》浮槎上天河，即往来天河的舟。语义 A 用一叶金色实心月牙形船身（凹口朝上）载一颗暖金星，一个剪影同时盖住「星」与「船」，是唯一同时容纳二者、且不引入具体型号识别负担的方案。

暖金只落在主体图形（舟 + 星）上，冷青星点仅 3 颗、小而弱，强调色覆盖远小于 10%，不满屏金。

安全区

主体（舟 + 星）bounding box 约 x 224–800 · y 373–668，全部收敛在画布中央 80% 安全区之内，距边缘 ≥ 10%，为 iOS squircle 裁切与平台 UI 留足余量。

40pt 可辨性论证

  • 承重剪影是「金色实心月牙 + 五角星」两块实心面，与深空底对比约 10:1，远高于 3:1 阈值。
  • 船为实心面而非细弧线，40pt 下读作「舟 / 月」而非「星轨」；冷青星点消失不损主识别。
  • 无文字、无细线承重，缩放后仍为两块实心剪影，Spotlight 下可辨。

红线合规

  • 无 NASA 标识，无「空间站」意象，无现成航天机构徽标；素材全自制矢量。
  • 「槎」字不进 icon，不放任何文字，文字解释由副标题承担。

技术规格

  • iOS 26 目标；App Store Connect 收 1024×1024 PNG、无 alpha 通道、不预裁圆角（系统裁 squircle）。
  • 无渐变堆砌、无毛玻璃、无发光描边滥用；仅少量单色线性渐变。
