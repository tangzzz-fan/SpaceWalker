# 星槎 · 尺度阶梯导航与常显尺子

交付文件：

- `index.html`：单文件交互稿。包含深色星图、深色太阳系、亮色星图、深色横屏地月系四个可交互屏幕，以及组件标注、token 与数值说明。
- `DESIGN_NOTES.md`：本说明。

直接打开 `index.html` 即可。页面无外部字体、图片、脚本或网络请求；所有场景、图标与星空均由内联 SVG / CSS 绘制。

---

## 1. 设计方向

把底部页签换成一台“深空测量仪”：

- 画面是主证据。星空、轨道、地月与空间站占满主体，控件只以必要的固体表面浮在边缘。
- 尺度是主轴。右侧四个节点承担四层跳转，顶部一条常显尺子承担“现在看到多远”。
- 暖金只做两件事：标记当前层，标记主操作。信息、尺子、辅助线全部使用冷青与中性灰。
- 不用玻璃、模糊、发光描边、渐变叠加。分界一律 1px 发丝线，圆角只用 14 / 8。

亮色不是把深色反相：背景回到 `#F6F7F8`，表面变白，暖金加深为 `#8A5A16`，并把冷青调整为 `#2F6F8A`，让 11pt 信息文字在白底上仍有足够对比。

## 2. A–D 的裁定

### A. 阶梯位置：右侧悬浮竖排

选择右侧悬浮。四个节点各 44×44pt，间隔 8pt，总高 200pt，位于画面中段偏下，右手拇指自然覆盖。节点右缘距屏幕 8pt，文字向左展开 84pt，不占画面中心。

未采用：

- **底部四行**：4 × 44pt + 3 × 8pt = 200pt，再加安全区与主操作，约 180pt 的视场会被持续吃掉，主画面退化为横条。
- **左侧竖排**：右手单手握持时需要跨过屏幕或换手；左侧留给场景标注也更有价值。
- **横向分段控件**：四个中文层名并排后每个目标只剩约 80pt 宽，且与底部主操作争夺同一块“拇指区”。

### B. 尺子位置：顶部独立细条

放在 44pt 应用状态条下方，不并入阶梯节点。固定区间与实时读数必须同时可见，合并进节点会让每个节点变成两行，破坏 44pt 目标与阅读节奏。

结构：

- 左：固定区间原文。
- 右：实时读数，独立于固定区间。
- 中：全局对数轨，亮起当前层的区间，标记沿轨移动。
- 下：`10^0` 与 `10^20 m` 两个端点。

固定区间永远只承担“这层的边界是什么”；读数承担“此刻看到多远”。两者职责分开，避免转场时单位切换与文案抖动。

### C. 当前层视觉：暖金唯一

- 当前：暖金 12pt 标签 + 8pt 实心点。
- 可达非当前：次文字色 12pt + 6pt 实心点。
- 隔层下钻：30% 不透明度 + 空心点 + 原生 `disabled`，点了不动。
- 按压：`scale(.96)` + `#141922` 表面，150ms linear。

不可达状态同时使用颜色、形状与原生禁用语义，不只依赖颜色。

### D. 一次性提示

文案固定为“已恢复姿态跟随”。

- 只在上行回到星图时出现。
- 32pt 高、8pt 圆角、1px 发丝线、11pt 文本。
- 位于上下文控件上方，不覆盖尺子与主操作。
- 进入 280ms easeOut，停留 2s，退出 150ms linear。
- `role="status"` 自动播报；`pointer-events: none`，不拦截操作。
- 一次页面会话只出现一次，用内存标记；不依赖可能被沙盒阻断的存储。

## 4. 阶梯导航语义

四个节点始终渲染。

| 目标 | 当前层以上 | 当前 + 1 | 当前 + 2 及以下 | 当前节点 |
|---|---|---|---|---|
| 行为 | 可跳 | 可跳 | 禁用、点了不动 | 单击无动作；双击/键盘激活回全览 |
| 视觉 | 次文字色实心点 | 次文字色实心点 | 30% 空心点 | 暖金标签与点 |

其他实现细节：

- 原生 `<button>`，每项 84 × 44pt；垂直间隔 8pt。
- 当前节点 `aria-current="step"`；不可达节点使用 `disabled`。
- 屏幕阅读器可读名称包含层名与“当前层 / 可跳转 / 不可直达”。
- 键盘 Enter / Space 在当前节点上等价于双击：回到本层全览。
- 双击其他节点不会误触发回全览：只有第一次点击时目标已经是当前层，才进入双击候选。
- 横屏改为横排，四个节点等宽并排，仍保留 44pt 高与 8pt 间隔。

## 5. 常显尺子与插值

### 固定文案

四层固定区间严格使用以下原文，不做自动单位换算：

| 层 | 固定区间 |
|---|---|
| 星图 | `4–3000 光年` |
| 太阳系 | `0.4–30 AU` |
| 地月系 | `350 km–38 万 km` |
| 天宫一号 | `约 10 米` |

### 对数域

全轨定义为：

```text
log10(distance in metres): 0 → 20
x% = log10(d) / 20 × 100
```

四个区间在轨上的近似位置：

| 层 | log10(m) | 轨上位置 | 默认读数 |
|---|---:|---:|---:|
| 星图 | 16.58–19.45 | 82.9%–97.3% | 10^18.2 m |
| 太阳系 | 10.78–12.65 | 53.9%–63.3% | 10^11.2 m |
| 地月系 | 5.54–8.58 | 27.7%–42.9% | 10^7.2 m |
| 天宫一号 | 0.90–1.15 | 4.5%–5.8% | 10^1.0 m |

读数采用 `10^x m` 的写法，全程 11pt，不切换光年 / AU / km / m。原因：

1. 跨层时单位切换会让读数跳动，且难以判断是否单调。
2. 科学计数法的字符宽度稳定，不会把右侧读数区撑开。
3. 不引入小于 11pt 的上标；`10^18.2 m` 在 11pt 下完整可读。
4. 固定区间仍保留全部人类可读单位，两个信息层互不替代。

### 插值规则

- 时长 450ms。
- 缓动：easeInOut cubic。
  - `t < 0.5`: `4t³`
  - `t ≥ 0.5`: `1 - (-2t + 2)³ / 2`
- 每帧计算后与上一帧比较：
  - 下行只允许减小；
  - 上行只允许增大。
- 如果转场中途再次切层，取消旧动画，从“当前已经显示的数值”起算，而不是从旧目标重算。
- 读数容器有固定最小宽度并使用 tabular numerals；标记与区间条都是绝对定位，不参与布局。
- 标记不跳格；读数以 0.1 为最小显示单位，达到 450ms 内的可读与稳定平衡。
- `prefers-reduced-motion: reduce` 时直接跳到终值，信息状态不变。

尺子的固定文案、轨道端点、容器高度在四层中保持一致，因此转场没有纵向或横向抖动。

## 6. 场景与控件

### 场景

- **星图**：程序生成星点，标注参宿四、织女星、比邻星；辅助线为圆形视场。
- **太阳系**：四条对数压缩轨道、地球 `1 AU` 标注；辅助线为十字测量轴。
- **地月系**：地球线框、月球轨道、近地轨道与天宫点；距离非等比，近地轨道放大。
- **天宫一号**：线稿空间站、太阳翼、对接端、尺寸线；辅助线为测量网格。

所有比例说明直接写在画面内（“轨道对数压缩 · 非等比”“结构示意”等），避免把示意误读为精确比例。标注中的真实距离使用真实值。

画面可拖动，`±24px` 软限位。没有捏合缩放，因此不存在越界缩放。

### 控件

- 「…」打开观测说明小面板；280ms easeOut，显式关闭按钮，Escape 与外部点击关闭。
- 「标注」切换星体/距离标注，默认开。
- 「辅助线」切换视场/十字轴/网格，默认关。激活态用冷青下划线，不使用暖金。
- 「全览」将拖动位移归零，450ms easeInOut。
- 主操作随层变化：下钻至太阳系 → 下钻至地月系 → 下钻至天宫一号 → 回望星图。
- 从任意下层回到星图时，若提示尚未出现过，则显示一次“已恢复姿态跟随”。

- 亮色冷青 `#2F6F8A` 是任务书未给出的派生 token。原冷青在 `#F6F7F8` 上作为 11pt 文本对比不足；`#2F6F8A` 保持信息层语义并提高可读性。

- 深色 `#F2F4F8` / `#05070D`、`#9A9DA2` / `#05070D`、`#6FA8C8` / `#05070D` 均高于 4.5:1。

## 8. 新增数值与理由

任务书未直接给出的数值，单列如下：

| 值 | 理由 |
|---|---|
| 阶梯总高 200pt | 4 × 44 + 3 × 8；四节点常显但不压制主画面 |
| 阶梯列宽 84pt、右缘 8pt | 容纳最长“天宫一号”12pt 标签与 8pt 当前点；同时保持“贴边细栏” |
| 尺子高 56 / 48pt | 竖屏容纳两行 11pt、轨与端点；横屏压缩 8pt 让出场景 |
| 全局对数域 10^0–10^20 m | 覆盖天宫约 10m 到星图 3000 光年；读数无需换单位 |
| 读数保留 1 位小数 | 450ms 内变化可读，字符宽度稳定，避免推动布局 |
| 标记宽 2pt | 在 1px 轨道上可辨识，不引入发光 |
| 当前节点点径 8pt / 默认 6pt | 形状差异补充颜色差异 |
| 禁用透明度 30% | 层名仍可辨认，但明显弱于可跳转；配合空心点 |
| 水平拖动范围 ±24pt | 足以感知“全览”复位，又不会拖出场景边缘 |
| 焦点环 2px / 偏移 2px | 透明节点与金色主操作上均可见 |
| 提示 32pt / 2s | 一行状态，不压尺子与主按钮 |
| 亮色青 `#2F6F8A` | 让 11pt 信息层在白底上可读 |
| 金色上的文字 `#05070D` / `#F6F7F8` | 深 / 亮主题各自保持主操作对比 |
| 双击确认窗口 500ms | 防止“先切层、后双击”被误判为回全览；内部行为，不出现在 UI 文案 |

## 9. 无障碍与键盘

- 所有可操作控件为原生按钮；目标最小 44pt。
- 当前阶梯节点 `aria-current="step"`；不可达节点 `disabled`。
- 上下文开关使用 `aria-pressed`；激活态同时有文字颜色与冷青下划线。
- 面板有显式关闭按钮，打开后焦点进入关闭按钮，关闭后回到「…」。
- 颜色不是唯一线索：当前状态有暖金 + 实心点 + `aria-current`；不可达状态有空心点 + 30% 弱化 + disabled。
- 视觉读数标记为 `aria-hidden`，最终状态通过 `aria-live="polite"` 的隐藏区域播报，避免 450ms 内逐帧朗读。
- 键盘：Tab 遍历所有控件，Enter / Space 激活按钮；Escape 关闭说明面板。
- 场景本身不承载唯一信息：固定区间、层名、问题与控件均在可访问树中。
- 场景拖动不是唯一入口；“全览”按钮提供等价复位操作。
- 焦点环使用主题主文字色，不依赖暖金或冷青。
- 不依赖外部字体，避免字体加载导致的尺寸跳动。

## 10. 假设与边界

1. **状态栏占用**：竖屏 402 × 874 包含 iPhone 系统安全区；产品头部从 59pt 安全区下方开始。若交付目标改为“扣安全区后的 402 × 874”，总高度需再加 59 + 34。
2. **横屏画板**：874 × 402 为应用表面，不含 iPhone 横屏系统状态栏和 Home Indicator；四个节点、尺子和主操作都仍在安全画板内。
3. **读数形式**：为了保持 11pt 与跨层稳定，使用 `10^x m` 的纯文本科学计数法，不使用需要更小字号的上标。固定区间仍使用任务书原文单位。
4. **场景比例**：星图、轨道、地月距离是示意，不宣称等比例；状态条与场景内均明确标注“非等比”。星体距离、AU、月球距离和空间站长度使用真实/任务书数值。
5. **一次性提示**：按“页面会话”实现；刷新页面后可以再次出现，便于评审演示。没有使用 localStorage，避免沙盒预览阻断。
6. **交互稿范围**：实现了切层、上下行约束、双击回全览、尺子插值、标注/辅助线开关、拖动、说明面板、一次性提示与键盘操作。没有实现真实相机、真实天文数据查询、陀螺仪姿态或捏合缩放手势；任务书明确要求“不做捏合越界”。
7. **多屏关系**：`index.html` 是设计板，包含多个独立、可交互的手机实例；不是在应用内提供屏幕切换器。每个实例各自维护当前层、拖动位移与开关状态，一次性提示在页面级别共享。
8. **验证状态**：按本轮生产约束未运行浏览器预览、截图或 HTML 校验；交付为静态文件，直接打开查看。所有场景与图标均为内联代码，无外链资源。
