阅读顺序

一个屏幕，一条主线

层名与问题 → 固定区间 → 实时读数 → 主画面 → 阶梯 → 上下文控件 → 主操作。暖金不参与任何装饰性信息，避免与当前层竞争。

A–D 设计裁定

实现选择

A / POSITION

右侧悬浮竖排

四节点总高 200pt，落在画面中段，右手拇指自然可达。底部四行会吃掉约 180pt 视场，仅作为被否决对照。

B / RULER

顶部独立细条

固定区间在左，读数在右，轨道表示 10^0–10^20 m 的全局对数域。跨层不换单位，读数单调。

C / CURRENT

暖金只给当前层与主操作

可达节点用次文字色；隔层下钻降为 30% 空心点。不可达不只靠颜色，还靠形状与 disabled 语义。

D / HINT

一次性低位提示

只在上行回星图时出现，位于控件上方，2 秒后消失；一次页面会话仅出现一次。

尺子高 56 / 48pt竖屏容纳两行 11pt、轨道与端点；横屏压到 48pt 让出主画面。
全局轨 10^0–10^20 m覆盖天宫 10m 到星图 3000 光年，读数不跨层换单位。

禁用 30% 不透明度层名仍可辨认，但明显弱于可达节点；配合空心点避免只靠颜色。
焦点环 2px / 偏移 2px透明节点与金色主按钮上都能稳定看见键盘焦点。
提示条 32pt / 2s只占一行，不压尺子与主按钮；2 秒完成一次状态告知。
亮色青 #2F6F8A原冷青在白底上 11pt 对比不足；该值保持信息层角色并达到 4.5:1。
画面拖动 ±24px提供“回全览”可感知的视图偏移，同时不把场景拖出安全范围。
