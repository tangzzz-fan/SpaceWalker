## 1. 这个产品到底是什么

不是 AR 应用（AR 链路已整条移除，ticket 063），是**一个可以用手摆弄的随身宇宙**，三个房间：

| 房间 | 用户实际做的事 | 不可替代性 |
|---|---|---|
| 星图 | 举起手机，星空跟着手腕转；能切到「今夜此刻」的真实天空；中国星官与西方星座并存 | 301 个星官 + 88 星座同屏，国内独一份 |
| 太阳系 | 点选、拖拽、缩放、拖时间轴看公转 | 常见，但是入口与教学层 |
| 天宫一号 | 拆开、装回、让神舟对接；剖面看舱内；工程图看尺寸；最后看它再入烧毁 | **App Store 上没有第二家** |

一句话：**看星 → 懂轨道 → 亲手拆一艘真的飞船**。

命名必须同时容得下「星」和「船」，否则只能盖住三分之一。

## 3. 为什么是「星槎」

**字面**：槎（chá）= 木筏。星槎 = 往来天河的舟。

**出处**：晋·张华《博物志》载海边人年年八月见浮槎往来，乘之而去，至一处见织女牵牛——这是「浮槎上天河」的原型；明·费信《星槎胜览》又把「星槎」用作远航的记录。**它既是看星，也是乘船去星海。**

**为什么比其它候选好**：

- 「举手观星」准确但窄：用户看到名字会以为只有观星，点进来发现能拆飞船是惊喜，但**上架名不该靠惊喜**。
- 「司天」「巡天」都偏机构/工程语感，能盖住天文，盖不住「亲手拆一艘飞船」这件事。
- 「星槎」两字，把「星空」与「载具」压在一起，正好对应产品的两条主线（星图 + 天宫），而且不碰「空间站」这条史实红线。
- 两字、独字无歧义、检索近乎零竞争。

**已知风险**：槎是生僻字，用户可能读不出。这是有意的取舍——生僻带来记忆点与检索独占，代价是首屏必须有一句解释。App Store 副标题与首屏文案承担这件事，不在名字里解释。
