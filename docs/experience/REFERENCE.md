# 体验参照库

用途：只记录"它怎么解决空间感、尺度感、手感"，不写功能清单。每个参照必须亲手在真机上用过再填，禁止凭印象填。

## 记录格式

| 产品 | 放置精度 | 遮挡处理 | 选中反馈 | 哪里假 |
|---|---|---|---|---|

- **放置精度**：落点是否贴合表面、是否漂移、是否穿模。
- **遮挡处理**：现实物体挡住虚拟物时是否可信；没有遮挡时靠什么补偿。
- **选中反馈**：怎么知道"选中的是它"，视觉/触觉/音频各做了什么。
- **哪里假**：第一眼露馅的地方，一句话。
