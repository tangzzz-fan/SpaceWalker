# 每日体验日志

规则：每天 5 分钟，只记录，不改代码。产品打磨的素材来自"情绪"那一栏，不是来自功能清单。

## 模板

### YYYY-MM-DD

- **我做了什么**：（放置了几次、走了几步、试了哪个手势）
- **我观察到**：（具体到一次操作，不写"感觉还行"）
- **我的情绪**：烦 / 惊 / 累 / 爽，附一句为什么
- **我因此怀疑的假设**：（对应 PRD 的 G1–G5 或某条 FR）
- **明天要验证的一件事**：（只写一件）

- 我观察到：—

## 使用规则

1. 一次记录不超过 5 行，写长了就不会坚持。
2. "烦"和"累"比"好"更有价值，优先记。
3. 连续 3 天记到同一类问题，升级为 ticket 或 kill criteria 的触发条件。
